## 一、认证动态

### 1. AWS SAP-C03：10月27日开报，$300，180 分钟，旧版 11/16 停考

**一句话**：持 SAP-C02 的考生必须在 11 月 16 日前考完旧版，否则只能改考新版。

AWS Certified Solutions Architect – Professional 从 SAP-C02 升版到 **SAP-C03**，10 月 27 日同步开放全语言报名，正式考试从 11 月 17 日起开放。

| 项目 | 旧版 SAP-C02 | 新版 SAP-C03 |
|---|---|---|
| 最后报名 | — | — |
| 最后考试 | **2026-11-16** | 2026-11-17 起 |
| 定价 | $300 USD | $300 USD |
| 时长 / 题数 | 180 分 / 75 题 | 180 分 / 75 题 |

新版重点变化：新增 **11 项 GenAI/Agentic AI 技能**、7 项云原生技能、6 项 DevSecOps 与可观测性技能，以及 AWS KMS 的**后量子密码学**（ML-DSA + ML-KEM）。五大领域（云原生设计、安全、成本优化、弹性与迁移、卓越运营）保持不变。

对 JR 学员来说：目前持 SAP-C02 备考的同学，**10 月 27 日前不需要做任何改变**；10 月 27 日之后如果还没考，建议直接转备 SAP-C03，因为两本证含金量相当，但新版更贴近 2026 年的实际工作场景（Bedrock + Agentic AI + 后量子加密）。

> 来源：[AWS Training and Certification Blog — September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

---

### 2. AWS DVA-C03：10月27日开报，$150，130 分钟，加入 Amazon Q 与 Kiro

**一句话**：Developer Associate 换代，新版直接考 Amazon Bedrock、Amazon Q 和 Kiro，旧版 DVA-C02 最晚 11 月 30 日。

AWS Certified Developer – Associate 同步升版到 **DVA-C03**，10 月 27 日开放报名，12 月 1 日正式开考。

| 项目 | DVA-C03 |
|---|---|
| 定价 | **$150 USD** |
| 时长 / 题数 | 130 分 / 65 题（50 计分 + 15 预研） |
| 合格线 | 720 / 1,000 |
| GA 日期 | 2026-12-01 |

新增内容要点：
- **AI 安全**新增独立 Task 2.3
- 全领域加入 AI 辅助开发场景
- 容器管理：ECR、ECS、EKS、Fargate
- 新服务：**Amazon Bedrock**、**Amazon Q**、**Kiro**

注意范围外内容（不考）：Prompt engineering、RAG 架构设计、AI 模型选型、SageMaker AI、AI 治理框架。

> 来源：[AWS Training and Certification Blog — September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 3. AWS MLA-C02 Beta：$75 考完，GA 是 2027-01-14

**一句话**：ML Engineer Associate 已进入 Beta 阶段，Beta 价格 $75，比正式版省一半不止，有备考计划的早考早省。

AWS Certified Machine Learning Engineer – Associate 第二版（**MLA-C02**）Beta 已于 9 月 29 日开考，英文版正式 GA 定于 **2027 年 1 月 14 日**，届时 MLA-C01 同步退役。

| 项目 | MLA-C02 Beta |
|---|---|
| 价格 | **$75 USD**（仅 Beta 期） |
| 时长 / 题数 | 170 分 / 85 题 |
| 语言 | 仅英文（Beta 期） |
| 考试渠道 | Pearson VUE |

新版增加内容：**生成式 AI**、**Agentic AI**、基础模型 / LLM 应用、扩展 Amazon Bedrock 内容。四大领域框架不变。

MLA-C01 英文版已于 9 月 28 日停考（日文 / 韩文 / 简体中文版保留至 2027 年 1 月 14 日）。

> 来源：[AWS Training and Certification Blog — September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 4. 微软 AB-400 已上线：PL-400 于 10/16 正式切换，Power Platform + AI Agent

**一句话**：PL-400 已于 10 月 16 日关闭报名，AB-400 同日上线，考的是 Power Platform 开发者 + Copilot Studio + AI Foundry Agent，通过后仍然是 Power Platform Developer Associate。

Microsoft 将 PL-400 正式更名升级为 **AB-400**（Extending Microsoft Power Platform Solutions with Code and AI），切换节点是 **2026 年 10 月 16 日**：

- **PL-400**：10 月 16 日起关闭新报名；已报名者可继续参考至 **10 月 30 日**
- **AB-400**：10 月 16 日上线，仍授予 **Microsoft Certified: Power Platform Developer Associate** 认证

内容变化（来源为微软官方 TechCommunity 公告）：
- 领域从 6 个精简为 4 个
- 新增：**Microsoft Foundry Agents**、**Model Context Protocol（MCP）服务器**、**Copilot Studio 工作流**、Power Apps 代码应用
- AI / Agentic 内容比重大幅提升

价格以 Microsoft Learn 官方考试页为准，可用 Microsoft Exam Replay 组合购买降低试错成本。

> 来源：[Microsoft Tech Community — Updates to Azure Cosmos DB and Power Platform Developer Certifications](https://techcommunity.microsoft.com/t5/the-skills-hub-blog/updates-to-azure-cosmos-db-and-power-platform-developer/ba-p/4528353)

### 5. Azure AI-200：Azure AI Cloud Developer Associate，120 分钟，10/7 更新

**一句话**：面向 Azure AI 后端开发者，考容器化方案 + AI 数据管理 + Azure SDK + 安全监控，不是纯 AI 理论，是工程实操。

Microsoft Certified: Azure AI Cloud Developer Associate（考试代号 **AI-200**）已正式上线，页面最新更新时间为 **2026-10-07**。

考试概要：
- 时长：**120 分钟**
- 考试渠道：Pearson VUE
- 支持语言：英文、阿拉伯语、简体 / 繁体中文、法语、德语、印尼语、意大利语、日语、韩语、葡萄牙语、俄语、西班牙语

考试覆盖领域：
1. 在 Azure 上开发容器化方案
2. 使用 Azure 数据管理服务构建 AI 方案
3. 接入并消费 Azure 服务
4. Azure 方案的安全、监控与故障排查

这本证替代原 AZ-204（Azure Developer Associate），但定位更偏 AI 后端。如果你目前在学 Azure 开发，直接走 AI-200 路径比 AZ-204 更有前景（后者已于 2026 年 7 月 31 日退役）。

> 来源：[Microsoft Learn — Azure AI Cloud Developer Associate (AI-200)](https://learn.microsoft.com/en-us/credentials/certifications/azure-ai-cloud-developer-associate/)

## 二、免费 / 限免课程

### 1. Hugging Face Agents Course — 免费，完课可领证书

**适合**：想系统学 AI Agent 开发的工程师，有 Python 基础即可入门
**链接**：[https://huggingface.co/agents-course](https://huggingface.co/agents-course)

课程覆盖范围非常实用：
- AI Agent 的设计与评估框架
- 三大主流 Agent 开发框架：**smolagents**、**LlamaIndex**、**LangGraph**
- 最终项目：在 **GAIA benchmark** 上提交你的 Agent 成绩

每章学习节奏约 **3-4 小时/周，持续约 1 周/章节**，适合利用工作日晚上跟完。完成作业后可以申领免费结课证书（Hugging Face 官方认可）。2026 年 10 月是 Agent 开发的热门话题，这门课完全匹配当前市场需求。

---

### 2. Stanford Probability for AI（pai.stanford.edu）— 免费，10/9 已开课

**适合**：想补 AI 数学基础（概率论）的开发者、备考 ML 认证的同学
**链接**：[https://pai.stanford.edu/](https://pai.stanford.edu/)

斯坦福 2026 年秋季课程，**10 月 9 日已经开课**，免费无付费门槛。课程学习周期约 **6 周**，每周少量专注学时，设计目标是连接概率论与神经网络基础。

课程亮点：包含实操项目，如"AI Word Detective"应用，边学边做，不是纯理论堆砌。如果你在备考 AWS MLA-C02 或 Google Cloud ML Engineer，这门课能帮你系统补上考试里最容易失分的数学板块。

---

### 3. Anthropic Claude Academy — 免费徽章，含 MCP 构建者路径

**适合**：需要快速上手 Claude API 的开发者，或想了解 MCP 协议的工程师
**链接**：[https://academy.claude.com/](https://academy.claude.com/)

Anthropic 官方学习平台，每门课约 **2.5–4 小时**，完成后颁发免费徽章。课程路径包括：
- Claude 能力与使用边界（适合产品和运营）
- Builder 路径：MCP 集成、工具调用、多轮对话设计

没有任何订阅费，直接用 Anthropic 账号登录即可学习。MCP 在 AB-400 和 Power Platform 新版考试里都出现了，这门课能帮你提前摸清 MCP 是什么。

---

### 4. fast.ai — Practical Deep Learning for Coders，免费，13.5 小时

**适合**：有 Python 基础、想直接动手训练模型的工程师，不适合纯理论爱好者
**链接**：[https://course.fast.ai/](https://course.fast.ai/)

Jeremy Howard 主讲，课程采用"从实战到理论"路线——先跑通模型，再解释原理。覆盖视觉、NLP、表格数据、推荐系统。Part 2（30+ 小时）深入到从零实现 Stable Diffusion 的核心方法。

全部免费、无付费墙、无证书，但内容扎实程度远超大多数付费课。适合作为 AWS MLA-C02 备考的补充实践资料。

## 三、JR Academy 学员行动建议

1. **持 SAP-C02 备考的同学**：10 月 27 日前照常走旧版备考路线；如果还没报名，**建议等 10 月 27 日直接报 SAP-C03**——新版才发布 $300 价格不变，但内容更贴近 2026 年面试题。把 [AWS 官方博客的考试变更说明](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)收藏起来，确认你的备考材料覆盖了 Bedrock 和后量子密码学部分。

2. **准备考 DVA-C02 的同学**：旧版最晚 11 月 30 日截止，**这个月是最后窗口**。如果备考进度 70% 以上，冲旧版；如果刚开始，直接转 DVA-C03 材料（12 月 1 日 GA），新版加了 Amazon Q 和 Kiro 但整体难度相当。

3. **Power Platform 开发者**：PL-400 已经关闭报名，手头还有 PL-400 报名凭证的最晚 10 月 30 日考完。从现在开始备考直接走 **AB-400**，重点补 Copilot Studio 和 Microsoft Foundry Agent 内容。

4. **AWS ML Engineer 方向**：MLA-C02 Beta 价格只有 $75，比正式版（预计 $150+）省一半以上。Beta 期限未公布，**建议近期评估一下是否值得直接报名 Beta**，通过后同样有效。

5. **这周空出 3 小时**：去 [Hugging Face Agents Course](https://huggingface.co/agents-course) 把第一章跑完。不管你在备哪本证，2026 下半年 AI Agent 出现在了几乎所有云认证的新增内容里（AWS SAP-C03、DVA-C03、MLA-C02、Azure AI-200、AB-400 全部涉及），先建立一个实操概念，备考效率会高很多。
