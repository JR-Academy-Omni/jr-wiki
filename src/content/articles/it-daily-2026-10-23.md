## 一、认证动态

### 1. Databricks Data Engineer Professional 新版10月9日上线，代码开发考点比重升至23%

**一句话**：Databricks 旧版 DE Pro 考试10月8日已停考，新版正式接棒，$200 报名费不变，但 AI 与流处理新考点大幅增加，旧题库已出现盲区。

旧版 Databricks Data Engineer Professional 于2026年10月8日停考，新版从10月9日开始接受报名。两者之间没有过渡期，正在备考的人需要确认自己注册的是哪个版本。

**新旧版本关键参数对比**

| 项目 | 旧版 | 新版（2026-10-09 起） |
|---|---|---|
| 考试费用 | $200 | $200（不变） |
| 考试时长 | 120 分钟 | 120 分钟（不变） |
| 计分题数 | 59 题 | 60 题 |
| 考试语言 | 英语 / 日语 / 葡萄牙语 / 韩语 | 仅英语 |
| 考试领域数 | 10 个 | 9 个 |

**最重要的内容变化**

- **代码开发（Code Development）权重升至 23%**，是新版权重最高的单个领域
- **成本与性能优化升至 15%**，新增 Serverless 环境调优和 CLUSTER BY AUTO
- **数据摄取新增 Lakeflow Connect CDC 考点**，包含 SCD Type 1/2 实现
- **Apache Iceberg** 正式列入摄取格式和 CDC 目标
- **流处理新考点**：水位线（watermark）、检查点（checkpoint）、foreachBatch 写法
- **ai_query 函数**在 pipeline 中的用法新增为考点
- **ABAC（基于属性的访问控制）**新增，Unity Catalog 指标视图（metric views）也进入考点
- 旧格式（ORC、Avro、XML、纯文本）从摄取考点中移除

数据共享与联邦（Data Sharing and Federation）独立领域取消，内容并入数据摄取领域，占比从 7% 升至 12%。

如果你已经在刷旧版题库，要注意这些新增考点在旧题库里不会出现——Lakeflow Connect、ai_query 和 Apache Iceberg 都是2026年之后才进入 Databricks 主线的功能。建议去 Databricks Academy 下载最新版官方考试指南对照差异。

> 来源：[Databricks Data Engineer Professional: New Exam 9 Oct 2026 – Daily Debian](https://dailydebian.com/blogs/it-certification-news/databricks-data-engineer-professional-new-exam-october-2026)

### 2. Snowflake 四张认证批量退役：Snowpark + Data Scientist 11月1日截止，距今不足10天

**一句话**：Snowflake 正在整合认证体系，四张 Advanced/Specialty 认证分两批退役，最近的截止是11月1日，想考的现在就要报名。

Snowflake 今年下半年启动了认证体系大整合，四张现有认证即将下线，退役后无法再报考：

| 认证名称 | 考试代码 | 退役日期 |
|---|---|---|
| SnowPro Specialty: Snowpark | SPS-C01 | 2026-11-01 |
| SnowPro Advanced: Data Scientist | DSA-C03 | 2026-11-01 |
| SnowPro Advanced: Data Analyst | — | 2026-12-01 |
| SnowPro Advanced: Security Engineer | — | 2026-12-01 |

**11月1日的两张最紧迫**——离现在只有不到10天。如果你打算拿 Snowpark 或 Data Scientist 方向的证书，今天就要做决定：

- 要考旧版：现在去 [Snowflake Training](https://learn.snowflake.com) 报名约考，选时间要留出准备余量
- 直接放弃等新版：Snowflake 目前还没公布这几张证的替代认证代码，不确定等多久

对已持有这几张证的人：认证过期后无法续期，账户里的持证记录会保留但标注为"已退役"。目前 Snowflake 没有宣布新的替代路径，官方建议继续备考其他现行认证（如 SnowPro Core 或 SnowPro Advanced: Architect）。

### 3. Microsoft DP-700 英语考纲10月19日小幅更新，Workspace 设置和性能优化有新考点

**一句话**：DP-700（Microsoft Fabric Data Engineer Associate）10月19日发布了一次英语版考纲微调，主要涉及 Workspace 设置管理和性能优化两个子模块，现在备考的人要对照检查。

Microsoft 在10月19日对 DP-700 英语考试版本做了一次更新。备考站点把这次调整标记为"minor"，但有具体考点增删：

**调整内容（第三方备考站整理）：**
- **Workspace 设置管理子模块**：考纲描述更新，明确了 Fabric Workspace 配置中与 Data Activator、Mirroring 相关的配置项
- **性能优化子模块**：补充了最新 Fabric Runtime 相关调优考点（Delta Lake 查询优化在新 Runtime 下的行为差异）

三大考试领域（实施与管理分析解决方案 / 数据摄取与转换 / 监控与优化）的总体权重分布不变，通过分仍为 700/1000，考试时长仍为 100 分钟。

正在备考的人建议去 [Microsoft Learn DP-700 考试页面](https://learn.microsoft.com/en-us/credentials/certifications/fabric-data-engineer-associate/) 下载最新版 Study Guide（PDF 里有"Last modified"时间戳），对比你手头版本里 Workspace 管理和性能优化那两块有没有差异。

> 来源：[Microsoft DP-700 Complete Guide 2026 – Examcert.app](https://www.examcert.app/blog/microsoft-dp-700-complete-guide/)

**链接**：[https://skills.google](https://skills.google)

如果你是任何档位的 Google Cloud 付费用户（哪怕只是个人用 GCP 跑点小项目），整个 Google Skills 按需学习库全部免费，没有每月积分限制。免费注册，不需要绑信用卡。

### 2. AWS Skill Builder：500+ 免费课，官方 Cloud Practitioner Essentials 是最好的 CLF-C02 入门点

**适合**：完全没有云计算背景、想从 AWS CLF-C02 开始的人，或者已有目标认证（SAA / DVA）想找官方学习材料的人
**链接**：[https://explore.skillbuilder.aws/learn](https://explore.skillbuilder.aws/learn)

AWS Skill Builder 的免费层提供超过500门课程，不需要信用卡就可以注册。其中最值得优先完成的：

**Cloud Practitioner Essentials（CLF-C02 备考首选）**
- 8模块结构，覆盖核心服务 / 定价模型 / 安全 / 架构最佳实践
- 完成后覆盖 CLF-C02 约80%的考点
- 课程本身免费；考试本身 $100 USD（Pearson VUE 报名）

**已有认证目标的人**：SAA-C03、DVA-C03、SAP-C03 等对应的官方数字化课程在 Skill Builder 上也是免费的，不提供结业证书但是官方认可的备考材料。付费订阅（$29/月）才能解锁动手实验室，如果只是看视频备考，免费层完全够用。
