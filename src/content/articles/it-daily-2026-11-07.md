## 一、认证动态

### 1. AWS SAP-C02 只剩9天 — 新版 SAP-C03 本周一 GA

**一句话**：Solutions Architect Professional 四年一换，SAP-C02 11月16日是最后一天，SAP-C03 于11月17日正式上线。

AWS 在9月发布的认证更新里明确了时间节点：SAP-C03 注册通道已于10月27日开放，GA 交付日期定在11月17日。如果你还打算用 SAP-C02 刷证，今天（11月7日）到11月16日是最后9天。

**SAP-C03 改了什么**：考试域从4个扩展为5个，新增了生成式 AI 架构设计、后量子密码学、AI 工作负载的成本与弹性优化等考点，整体从"场景题"转向"架构关切"（安全/成本/韧性/运营）。考试格式保持不变：75题、180分钟、$300，Pearson VUE 在线和现场均可。AWS 认证3年有效期、续期要求不变，持有 SAP-C02 的不影响当前证书效力。

对正在准备 SAP-C02 的学员：如果复习已过80%，建议这9天内完成考试。如果才起步，不如直接对准 SAP-C03——新版考纲一旦发布，更多备考资源会快速跟进。

> 来源：[AWS Training and Certification Blog – September 2026 新增内容](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 2. AWS Advanced Networking Specialty（ANS-C01）年底整退，全球唯一无续任认证

**一句话**：AWS 罕见地"整退"了一门专业认证——ANS-C01 12月31日到期，不设替代考试，历史上首次。

过去几年 AWS 每次退场一门认证，都会同步推出替代版本（SAP-C02 → SAP-C03、DVA-C02 → DVA-C03）。这次 Advanced Networking Specialty 是例外：AWS 明确退出网络专项方向，不另开新题库。

ANS-C01 覆盖的内容包括 VPC 高级路由、Direct Connect 冗余设计、AWS Transit Gateway 大规模组网、混合云 DNS 架构等。这些内容日后可能分散进其他专业认证或 Solutions Architect Professional，但独立的「网络专项证书」通道将关闭。

对网络方向从业者的建议：12月31日前是最后机会。如果公司要求有 ANS 认证的候选人，这张证在未来数年内不会被新版本"刷新淘汰"，反而可能因为不再新增持有者而显得稀缺。

> 来源：[CertCrush – AWS Advanced Networking Specialty Retiring 2026](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026)

### 3. Microsoft AB-330 Supply Chain AI Consultant（Beta）现已开放

**一句话**：微软面向 Dynamics 365 供应链方向推出新 AI 认证，Beta 窗口期费用低、题库尚未锁定，是刷证时机。

AB-330 对应新认证 Supply Chain Management AI Consultant Associate，考核如何在 Dynamics 365 Supply Chain Management 上落地 AI 能力——涵盖需求预测 AI、供应链可视化 AI、以及与 Microsoft Copilot 的集成。

考试格式：100分钟，通过线700/1000分，Associate 级别。Beta 阶段有个特殊点：**成绩不会立即出来**，微软需要收集题目质量数据后统一评分，通常延迟4-6周。这意味着你无法第一时间知道结果，但 Beta 考试费用通常低于正式考试，题目难度数据尚未充分积累，整体通过率相对较高。

适合人群：有 MB-330（Dynamics 365 Supply Chain Management Functional Consultant）基础、或正在供应链/ERP 方向工作、想转向 AI 实施的从业者。

> 来源：[A Guide to Cloud – AB-330 Exam Tracker](https://www.aguidetocloud.com/guided/ab-330/)

### 4. AWS SAP 认证加入 Maintain 计划 Beta —— 续期新路径试水

**一句话**：AWS 把 Solutions Architect Professional 纳入 Maintain 计划 Beta，持有者可通过 Skill Builder 活动延长1年效期，无需重新考试。

AWS 社区论坛里有帖子确认，SAP-C02/C03 持证人可参与 Maintain 计划 Beta，通过 AWS Skill Builder 上指定的学习活动完成"保持现状"评估，认证效期延长1年。这是对传统"3年后必须重考"模式的第一次实质性松动，目前仍是 Beta 阶段，参与条件和具体学习量未完全公布。

对临近3年续期的 SAP 持证人：值得关注 Skill Builder 账户里是否出现 Maintain 相关入口，早参与 Beta 比等正式版本规则固定后再动手更有余量。

> 来源：[AWS Builder Center – SAP-C Maintain 社区讨论](https://builder.aws.com/content/3KAZmQ75pMn9ZwSSup7Xd9s5frp/passing-sap-c-before-it-retires-study-resources-exam-tactics-and-deep-dive-questions)

## 二、免费 / 限免课程

### 1. Hugging Face MCP Course（与 Anthropic 合作，免费证书）

**适合**：AI 工程师、想理解 Claude / AI Agent 底层协议的开发者
**链接**：[https://huggingface.co/learn](https://huggingface.co/learn)

MCP（Model Context Protocol）是 Anthropic 推出、已成为 AI Agent 生态事实标准的开放协议——Claude、Cursor、各类 Agent 框架都在用它对接外部工具。Hugging Face 和 Anthropic 合作推出了这门自学课，内容涵盖如何构建 MCP Server、如何让 LLM 通过 MCP 安全调用数据库/API/文件系统、以及常见的 MCP 安全问题。

课程自学节奏，完成评估后可领取**免费证书**（Hugging Face 证书不需要付费）。对于已经学过 AI Agents Course 的学员，MCP Course 是很自然的下一步——Agents Course 教了"怎么让 agent 决策"，MCP Course 教了"怎么安全地给 agent 插工具"。

> 来源：[Dev.to – 5 Free AI and CS Workshops You Can Start Now (Nov 2026)](https://dev.to/jathurshan_sownthararasa_/5-free-ai-and-cs-workshops-and-courses-you-can-start-now-nov-2026-a0i)

### 2. freeCodeCamp：MCP Security Fundamentals（约2小时，YouTube，免费）

**适合**：想快速了解 MCP 安全风险的开发者、Cloud Security 工程师
**链接**：[https://www.youtube.com/@freecodecamp](https://www.youtube.com/@freecodecamp)

freeCodeCamp YouTube 频道发布了约2小时的"MCP Security Fundamentals"课程，不需要注册账号，直接开播。内容覆盖 MCP 协议的信任边界、常见注入攻击面（Prompt Injection via MCP Tool Response）、防御模式和最小权限设计原则。

不提供证书，但适合快速建立 MCP 安全思维框架。对准备 AWS Security Specialty 或 Microsoft SC-500 的学员，这门课可以补充现有备考材料里"AI 工具集成安全"这块相对薄弱的内容。

### 4. Hugging Face Context Course（上下文工程，免费）

**适合**：已有 LLM 基础、想提升 AI Agent 实战能力的开发者
**链接**：[https://huggingface.co/learn](https://huggingface.co/learn)

这个方向在国内外 AI 工程圈讨论热度快速上升，因为 RAG + Agent 落地的最大坑恰好在这里：不是模型不够聪明，而是给模型的上下文太乱、太噪、或太短。课程免费，自学节奏，无需注册，直接在 Hugging Face 官网浏览即可。

## 三、JR Academy 学员行动建议

1. **今天到11月16日（9天）**：如果 SAP-C02 复习进度已超过70%，抓紧这9天预约考试，$300 一次性通过。进度不足的直接切到 SAP-C03 官方考纲（AWS 官网已发布），新版 AI 相关题目恰好是 JR Academy DevOps/Cloud 课程的核心内容。

2. **12月31日前**：有网络工程背景的同学，把 ANS-C01 列入今年 Q4 计划。这是这门证最后的考试窗口，并且不会被新版本替代——持证稀缺性只会升高不会降。预约链接：[AWS Certification – ANS-C01](https://aws.amazon.com/certification/certified-advanced-networking-specialty/)

3. **Dynamics 365 方向**：有 MB-330 或供应链 ERP 经验的，趁 AB-330 还在 Beta，这是费用最低、题库最"不稳定"（对考生有利）的阶段。Beta 结束后通过率通常会下降。

4. **本周末**：在 Hugging Face Learn 注册 MCP Course 并完成第一个单元，配合 freeCodeCamp 的2小时 MCP Security Fundamentals，周末两天可以把 MCP 安全概念跑通——直接对应市场上 AI 工程师岗位描述里越来越常见的"MCP experience"要求。

5. **没有编程基础的**：CS50 2026 YouTube 版更新了，整个课程免费，今天可以开始看 Week 0（Scratch）热身，计划12月完成 Python 章节——这是进入 AWS Cloud Practitioner / AZ-900 备考的最低技术门槛。
