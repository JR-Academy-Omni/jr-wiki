## 一、认证动态

### 1. SAP-C03 本周正式上线，过关分数降至 720，新增 37 项 AI 技能考点

**一句话**：11 月 16 日是最后一次参加 SAP-C02 的机会，17 日起全球 Pearson VUE 和在线考场统一切换为 SAP-C03。

AWS Solutions Architect Professional 是整个 AWS 认证体系里含金量最高的考试，这次版本更新幅度相当大。

格式上，$300 USD 的考试费、75 道题（65 道计分）、180 分钟保持不变；但过关分数从 750 下调至 720（刻度 100-1000），对于"差一点没过"的选手是个小利好。考试结构变化更显著：域从 4 个扩展到 5 个，AWS 官方表示此次「retaining the core architectural competencies that the certification has always validated」（保留核心架构能力的前提下大范围扩充）。

新增的 37 项技能集中在四个方向：

- **生成式 AI 与 Agentic 架构**：Amazon Bedrock 的 Agent 编排、RAG 管道设计、Foundation Model 选型决策
- **云原生设计**：Serverless 进阶模式、EDA 事件驱动架构、跨区域弹性设计
- **数据与分析**：Lake Formation 权限模型、Redshift Serverless 架构决策
- **安全合规**：跨账号权限边界、IAM Identity Center 企业集成

另外，考题中的服务名称已切换为 AWS 推广的「短名」写法，考试时可点击 Help 按钮调出对照表。

如果你正在备考 SAP-C02，原有知识点不会白学，但要重点补充 Bedrock 和 AI 架构相关的 15-20% 新权重。官方考纲 PDF 已更新，直接在 AWS 认证页下载即可。

> 来源：[AWS Certified Solutions Architect – Professional 官方认证页](https://aws.amazon.com/certification/certified-solutions-architect-professional/)（考试代码 SAP-C03，$300 USD）；[CloudNinja：SAP-C02 vs SAP-C03 详细对比](https://cloudninja.pro/blog/sap-c02-vs-sap-c03)

### 2. Snowflake 双证 12 月 1 日退役，新「AI 治理与安全」Specialty（ADS-B01）已入册

**一句话**：Snowflake SEA-C01（Security Engineer Advanced）和 DAA-C01（Data Analyst Advanced）于 12 月 1 日停考，仅剩约 10 天窗口期。

从 Snowflake 官方认证目录（learn.snowflake.com/en/certifications/）直接确认：

| 认证 | 状态 |
|------|------|
| SEA-C01（Security Engineer Advanced） | Retiring December 1, 2026 |
| DAA-C01（Data Analyst Advanced） | Retiring December 1, 2026 |
| ADS-B01（AI Governance & Security Specialty） | 新上架，当前在册 |
| GES-C02（Gen AI Specialty） | 当前在册 |
| MLA-C01（MLOps Engineer Advanced） | 当前在册 |

SEA-C01 和 DAA-C01 均未宣布继任证书，12 月 1 日之后就没有这两条认证路径了。如果你已经备考到 80% 以上，本周末就应该锁定考位，不要等到 11 月 30 日最后一天的报名流量高峰。

新上架的 ADS-B01（AI Governance & Security）是个值得关注的信号：Snowflake 专门把 AI 治理与安全捆在一起出一门新 Specialty，说明数据平台层面的 AI 合规已成为企业真实需求。目前官方尚未公布考试题数、时长和价格，备考材料尚不完整，但可提前关注 Snowflake Horizon 安全框架和 Trust & Safety 文档做铺垫。

> 来源：[Snowflake 官方认证目录](https://learn.snowflake.com/en/certifications/)（直接列出退役日期与 ADS-B01 在册状态）

### 3. AWS MLA-C02 Beta 进行中：ML Engineer 认证换代，窗口期预计月底关闭

**一句话**：AWS ML Engineer Associate 完成 C01→C02 换代，Beta 阶段通常价格更低，但窗口期可能在 11 月底至 12 月初关闭，需立即确认报名状态。

根据 AWS Training & Certification 博客的更新公告，这次换代时间线为：

- **2026 年 9 月 1 日**：MLA-C02 Beta 英文版开放报名
- **2026 年 9 月 28 日**：MLA-C01 英文版正式停考
- **MLA-C01 日文 / 韩文 / 简体中文版**：Beta 期间仍可考

AWS 的 Beta 考试窗口通常持续 60-90 天，从 9 月 1 日算起，意味着正式版（GA）可能在 11 月底至 12 月上旬上线。Beta 阶段的策略价值在于：Beta 考试价格通常比正式版便宜，考题集中在核心知识点，刷分布通常高于最终版。

考纲方向上，MLA-C02 延续四大域结构，但大幅加入 Bedrock 和 SageMaker 新功能，重点考 ML Pipeline 的生产化、模型监控和安全合规。如果你有 SageMaker 实操经验，这是在正式版涌入大量考生之前「抢先入场」的时机。

**验证步骤**：访问 [aws.amazon.com/certification/certified-machine-learning-engineer-associate/](https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/) 确认 Beta 是否还在接受报名，价格会明确标注。

> 来源：[AWS Training and Certification Blog – MLA-C02 更新公告](https://aws.amazon.com/blogs/training-and-certification/updates-to-aws-certified-machine-learning-engineer-associate-mla-c02/)

## 二、免费 / 限免课程

### 1. Microsoft Learn：「Introduction to generative AI and agents」（完全免费，上月刚更新）

**适合**：没有 AI 开发背景、想从零理解 LLM 和 AI Agent 工作原理的 IT 从业者
**链接**：[learn.microsoft.com/en-us/training/modules/fundamentals-generative-ai/](https://learn.microsoft.com/en-us/training/modules/fundamentals-generative-ai/)

这个 Microsoft Learn 模块最后更新日期为 2026 年 10 月 28 日，属于刚刷新的内容。7 个单元覆盖：
- 大型语言模型（LLM）的运作原理
- Prompt 工程基础
- AI Agent 的核心概念与 Agentic AI 解决方案

官方描述原文：「Generative AI powers applications that can create content, answer questions, and assist with tasks.」整个模块无需付费，完成 Module Assessment 后可在 Microsoft Learn 个人档案展示通过标记。

适合配合 AI-900（Azure AI Fundamentals）或 AI-200（Azure AI Cloud Developer Associate）备考前的热身，特别是对 Agent 概念不熟悉的同学，这 7 个单元大约 2-3 小时就能完成。

### 2. Hugging Face AI Agents Course（免费，双证书，无截止日）

**适合**：懂基础 Python、想拿到 Agent 框架实战背书的 AI 工程师
**链接**：[huggingface.co/learn/agents-course/en/unit0/introduction](https://huggingface.co/learn/agents-course/en/unit0/introduction)

官方原文明确：「The certification process is completely free.」课程内容包含：
- **5 章正课** + **3 个 bonus 单元**（function-calling fine-tuning、可观测性与评估、Pokémon battle agents 实战项目）
- 三大主流 Agent 框架逐一实战：smolagents、LlamaIndex、LangGraph
- 如何把自己的 Agent 发布到 Hugging Face Hub

两种证书路径：
1. 完成 Unit 1 → **Fundamentals Certificate**
2. 完成 Unit 1 + 一个用例作业 + 最终挑战 → **Certificate of Completion**

没有截止日，但「Agent 工程师」的招聘热度还在高峰。做完最终挑战项目后，把代码推到 Hugging Face Hub 和 GitHub，对技术面试的加分比一张证书截图实在得多。

### 3. Google Cloud Innovators 免费计划：每月 35 积分，零成本刷 GCP 实验室

**适合**：备考 Cloud Digital Leader、Associate Cloud Engineer、Professional Data Engineer 或 Professional Agentic Architect 的学员
**链接**：[cloud.google.com/training/free-labs/](https://cloud.google.com/training/free-labs/)

加入 Google Cloud Innovators 免费计划（no-cost tier）可以拿到每月 35 个学习积分，用于 Google Skills（原 Cloud Skills Boost）的动手实验室。Google 官方博客原文：「Members of the no-cost Google Cloud Innovators program get 35 unrestricted learning credits every month.」

35 积分的实际使用情况：按 Google Skills 的积分消耗，单个动手实验室通常需要 1-5 积分，一个 Quest（主题系列）需要 10-30 积分。35 分在一个月里可以完成多个标准实验室，或者 1 个完整的备考 Quest，足够支撑大多数 Associate 级别认证的实验备考。

需要更多积分的选项：月付订阅 $29/月；年付开发者 Premium $299/年（含 $500 GCP 信用额度）；学生额外可申请 200 积分。

> 来源：[Google Cloud 官方博客：Google Cloud Innovators 免费积分](https://cloud.google.com/blog/topics/training-certifications/members-of-google-cloud-innovators-get-free-training-and-labs)

## 三、JR Academy 学员行动建议

1. **今天下载 SAP-C03 官方考纲**：访问 [aws.amazon.com/certification/certified-solutions-architect-professional/](https://aws.amazon.com/certification/certified-solutions-architect-professional/)，重点看新增的 Bedrock Agent、RAG 管道和 Agentic 架构相关 task statements。已经在备考 SAP-C02 的同学不用从头开始，只需补充 15-20% 新考点，重点是 Amazon Bedrock + Knowledge Base 的架构决策部分。

2. **Snowflake 安全 / 数据分析方向，本周末前报考 SEA-C01 或 DAA-C01**：12 月 1 日之后无路可走，官方也没有宣布继任证书。如果你已经完成 80% 以上的备考，这周末就应该锁定考位，不要等到最后一天的高峰。访问 Snowflake 官网考试门户完成预约。

3. **立即确认 MLA-C02 Beta 是否还在接受报名**：访问 AWS ML Engineer Associate 认证页，Beta 价格通常是正式版的一半左右。有 SageMaker 实操经验的同学，这是抢在 GA 价格上调前入场的最后机会。

4. **用 2 周拿下 Microsoft Learn Gen AI 模块 + HF Agents Course Unit 1**：两门课合计不超过 10 小时，完成后能拿到来自微软和 Hugging Face 的学习认证标记。配合 JR Academy 的 AI Engineering 课程，这两项是在技术面试中展示「不只是用过 ChatGPT，而是懂 Agent 架构」最快速的方式。

5. **现在注册 Google Cloud Innovators 免费计划，激活月度 35 积分**：即使今天还没开始备考 GCP，先注册激活，积分下月会自动刷新，不浪费。对于同时备考 AWS 和 GCP 双云的学员来说，零成本的 GCP 实验室配额是难得的资源。
