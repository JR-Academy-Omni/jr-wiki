## 一、认证动态

### 1. AWS SAP-C02 昨日截止，SAP-C03 正式开考

**一句话**：Solutions Architect Professional 新版 SAP-C03 于11月17日 GA，错过 SAP-C02 窗口的考生现在必须备考新版。

AWS 解决方案架构师专业级认证迎来一次版本切换。SAP-C02 的最后考试日期为 2026年11月16日，SAP-C03 的注册从10月27日开放，GA 交付从11月17日起算。两个版本的考试费均为 **USD $300**（官网注明"实际费用因汇率而异"）。

SAP-C03 在考题语言上做了调整：部分 AWS 服务名改用短称，例如将原本的全称缩写，考场会通过 Help 按钮提供对照表。英文版首先执行，其他语言版本滚动跟进。

如果你已经报了 SAP-C02 但还没考，这个窗口已经关闭。现在只有 SAP-C03 可选。备考资料在 AWS Skill Builder 和官方认证页均可找到。

> 来源：[AWS Exam Deadlines: SAP-C02, DVA-C02 and ANS-C01](https://dailydebian.com/blogs/it-certification-news/aws-sap-c02-dva-c02-ans-c01-deadlines-2026)（引用 AWS 官方认证页面数据）  
> 考试价格原文：[aws.amazon.com/certification/certified-solutions-architect-professional](https://aws.amazon.com/certification/certified-solutions-architect-professional/) — "300 USD"

### 2. AWS DVA-C02 本月30日截止，DVA-C03 接棒

**一句话**：Developer Associate 新版本月底切换，还没拿证的考生只剩两天考 C02。

Developer Associate 的截点比 SA Professional 晚了两周：DVA-C02 可以考到 **2026年11月30日**，DVA-C03 注册同样从10月27日开放。今天是11月28日，到截止只剩不到 48 小时。

如果你备考方向是 DVA-C02，今明两天是最后机会。否则就直接备 DVA-C03，官方学习路径已在 AWS Skill Builder 更新。

> 来源：[AWS Exam Deadlines: SAP-C02, DVA-C02 and ANS-C01](https://dailydebian.com/blogs/it-certification-news/aws-sap-c02-dva-c02-ans-c01-deadlines-2026)

### 3. AWS ANS-C01 年底退出，无继任认证

**一句话**：Advanced Networking Specialty 将于12月31日永久退场，AWS 未宣布任何替代认证。

ANS-C01 的退场信息来自 AWS 官方：**"This exam is being retired. The last day to take the exam is December 31, 2026."** AWS 没有给出任何继任考试代码，也没有宣布 ANS-C02 时间表。

这意味着如果你想在网络专项方向拿到 AWS 认证背书，12月31日前是最后机会。过了这个日期，该专项认证的通道就关闭了。建议提前在 AWS Pearson VUE 或 PSI 预约考场，年底档期通常较紧。

> 来源：[AWS Exam Deadlines: SAP-C02, DVA-C02 and ANS-C01](https://dailydebian.com/blogs/it-certification-news/aws-sap-c02-dva-c02-ans-c01-deadlines-2026) 引用 AWS 官方原文："This exam is being retired. The last day to take the exam is December 31, 2026."

### 4. Google Cloud 发布 Professional Agentic Architect 认证

**一句话**：11月11日正式上线，双考核（笔试 + 云端实操），两项均须通过，AI Agent 架构方向首个专业级认证。

Google Cloud 在 11月11日推出了 Professional Agentic Architect（PAA）认证，官方 Google Developer Forums 的发布帖原文写道："launched today, November 11!"  日文版则于11月19日跟进发布。

**考核方式：**
- Multiple-choice exam（proctored）：测试系统设计、架构标准、成本优化与安全治理
- Hands-on labs on Google Skills：在真实云环境中构建、测试和调试 AI agent workflow

官方明确指出："Both components are required to achieve the certification."（两项都必须完成才算通过）

这是 Google Cloud 第一个专门面向 AI Agent 领域的认证，定位是能够在企业生产环境部署可靠、安全、可扩展 agentic workflow 的技术从业者。考试官方价格页面未直接列明，建议到 cloud.google.com/learn/certification 确认。

> 来源：[Introducing the new Google Cloud Professional Agentic Architect certification – Google Developer Forums](https://discuss.google.dev/t/introducing-the-new-google-cloud-professional-agentic-architect-certification/412997)（Google 官方发布帖）  
> 原文引用："launched today, November 11!" · "Both components are required to achieve the certification."

### 5. Microsoft MS-102 本月30日截止，Microsoft 365 Admin 认证关闭

**一句话**：MS-102 是 Microsoft 365 Administrator Expert 的唯一考试，月底截止后这张认证就无法再获取或续期。

certificationcamps.com 收录了 Microsoft Learn 官方退场日期，原文如下："After November 30, 2026, you can no longer earn or renew the Microsoft 365 Administrator Expert certification."

现阶段 Microsoft 还没有公布继任的 M365 管理员专家级认证上线时间（AB-650 仍处于 Beta 阶段，GA 日期未定）。如果 M365 管理方向是你的考证优先项，11月30日前是最后机会。

> 来源：[Microsoft Certifications Retiring in 2026: Dates and Replacements](https://www.certificationcamps.com/microsoft-certifications-retiring/)  
> 原文："After November 30, 2026, you can no longer earn or renew the Microsoft 365 Administrator Expert certification."
