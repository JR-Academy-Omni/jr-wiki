## 一、认证动态

### 1. Google Cloud 新增 GAIL 认证：$99 面向产品经理和高管，不考代码

**一句话**：Generative AI Leader（GAIL）是 Google Cloud 今年新出的非技术认证，$99 / 90 分钟 / 50-60 道多选题，无先修课也无上机实验。

GAIL 的出现填了一个明显的空白——以往 Google Cloud 认证全是工程师向的，数据工程师、云架构师、ML 工程师，都需要动手实验。GAIL 专门给**不写代码的决策层**开了一条路：产品经理、数据分析师领导、企业转型负责人、咨询顾问，看完考纲就能感受到区别：

- **没有 Terraform / GCP CLI 考点**，不考任何实操命令
- **考什么**：生成式 AI 的商业应用场景、AI 治理与伦理、Gemini 在业务场景的能力范围与局限、AI 项目 ROI 评估框架
- **考试规格**：$99 USD，90 分钟，50-60 道选择题，在 Pearson VUE 考场或线上监考完成

对于想给团队做 AI 培训、或者想在简历上加一个 Google 官方认证但没时间备考技术证的职场人来说，GAIL 是今年最低门槛的 Google 认证入口。

> 来源：[Google Cloud Certification Changes 2026: Pearson VUE and AI Exam Overhaul](https://www.directcertify.com/blog/google-cloud-certification-changes-2026-pearson-vue-and-ai-exam-overhaul/)

### 2. Google Cloud PMLE 考纲 6 月 1 日起换轨 Gemini：RAG + Agent Builder 成新考点

**一句话**：Professional Machine Learning Engineer 的考纲 6 月 1 日正式更新，从 Vertex AI 管道导向转向 Gemini Enterprise Agent Platform，2026 年 6 月前的备考资料很可能已过时。

这次考纲更新的核心信号是品牌重命名后的内容重心转移：

- **新考点**：Vertex AI Agent Builder（构建 AI Agent 的托管平台）、Retrieval-Augmented Generation（RAG）架构设计、Model Garden 中的模型选型与部署
- **变轻的部分**：原有的 Vertex AI ML Pipelines 和 Kubeflow 管道细节权重下降
- **不变的**：ML 工程基础、数据准备、模型评估、监控与漂移检测

实操建议：正在备考 PMLE 的同学，把 Google Cloud 官方 [PMLE 考纲页面](https://cloud.google.com/learn/certification/machine-learning-engineer) 和 Vertex AI Agent Builder 文档加入必读列表，重点看 RAG 实现方式和 Agent 编排模式。

> 来源：[Google Cloud Certification Changes 2026](https://www.directcertify.com/blog/google-cloud-certification-changes-2026-pearson-vue-and-ai-exam-overhaul/)

### 3. Google Cloud ACE 考纲 6 月 30 日刷新：4 个权重领域 + AI 工具上题

**一句话**：Associate Cloud Engineer 英文版考纲 6 月 30 日起全面替换，结构调整为 4 个加权考试域，AI 工具和新存储产品正式纳入考点。

ACE 一直是云从业者最常先拿的 Google Cloud 认证（$200，120 分钟），这次更新是近两年最大的考纲调整：

- **4 个考试域**（具体权重以 Google 官方最新考纲为准）：建立云方案 / 配置云方案 / 部署与实施 / 确保云方案成功运行
- **新加入**：AI 辅助工具（Gemini in Cloud Console）、新存储产品（Google Cloud Hyperdisk）、Vertex AI 品牌重命名后的新服务名称
- **同步更新**：续期简短考试（renewal assessment）也已于 6 月 30 日同步刷新

如果你买了 2026 年 6 月前出版的 ACE 实战课程，强烈建议比对一遍最新考纲，特别是存储和 AI 工具部分。

> 来源：[Google Cloud Changed How You Take and Renew Certifications in 2026](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)

### 4. Microsoft AZ-802 上线：AZ-800 + AZ-801 合并单考，Windows Server 混合管理路线重组

**一句话**：AZ-800（配置 Windows Server 混合高级服务）和 AZ-801（配置 Windows Server 混合高级工作负载）已合并为 AZ-802，2026 年 9 月完成退场，Windows Server Hybrid Administrator Associate 认证保留。

这是微软今年第三次做"两考合一"，逻辑和之前 AZ-204→AI-200、AZ-500→SC-500 一样：减少碎片化，把相关技术整合成一张证。

关键信息：
- **原持有者**：已通过 AZ-800 和 AZ-801 的人，Windows Server Hybrid Administrator Associate 认证**不受影响**，会保留到到期日
- **新考生**：只需考 AZ-802 一科即可获得这张认证
- **AZ-802 内容**：整合了原 AZ-800 的 AD DS / Hyper-V 配置和 AZ-801 的 Kubernetes / 安全加固内容

同期已完成的其他合并参考：AI-102 退役（→ AI-103），AZ-204 退役（→ AI-200），AZ-500 退役（→ SC-500）。整体方向是把传统 Azure 运维证向 AI 集成路线迁移。

> 来源：[Microsoft Certification Retirements 2026: Every Change](https://vladtalkstech.com/microsoft-learning-and-credential-news/microsoft-certification-retirements-2026/)

### 1. Anthropic 10 门免费课上线 Coursera（10 月 13 日发布）

**适合**：教育工作者、开发者、小企业主、创意工作者——Anthropic 按职业角色分包设计，不需要编程基础的课程和开发者向课程清晰分开。
**链接**：[Coursera - Anthropic 课程目录](https://www.coursera.org/courses?query=anthropic)

这是今年 Anthropic 在 Coursera 的最大一次集中上线，10 门全新课程把目录从 12 门扩充到 22 门，全部免费，计划每月持续新增：

**非技术向（4 门）：**
- **AI Fluency for pK-12 Educators**（4 小时，与 Teach for America 合作）：AI 辅助备课、学生数据保护
- **AI Fluency for pK-12 Train the Trainer**（与美国教师联合会合作）：针对要给同事做培训的教育者，含完整课件和教学练习
- **AI Fluency for Small Businesses**（4 小时，与 PayPal 合作）：客服自动化、供应链辅助决策
- **AI Capabilities and Limitations**（4 小时）：AI 如何生成答案、记忆机制、prompt 对输出的影响——适合所有人的入门课

**创意向（1 门）：**
- **AI Fluency for Creative Work**：AI 在创意流程中的定位与边界

**开发者向（4 门）：**
- **Claude Code 101**（2 小时）：安装配置、任务委托、创建 subagent
- **Claude Platform 101**：API 调用和 Agent 循环的产品开发实战
- **Introduction to Subagents**：何时用独立 Agent、如何设计编排
- **Introduction to Agent Skills**：把反复用的 prompt 封装成可复用指令并与团队共享

**通用开发（1 门）：**
- **AI Fluency for Builders**（与 CodePath 合作）：产品开发中人类判断力和 AI 的结合点

### 2. Google Cloud 认证续期：用技能徽章代替重考（2026 年 7 月起）

**适合**：已持有 Google Cloud PCA / PDE / ACE / CDL 认证、即将到期但不想再花 $200 重考的人。
**链接**：[Google Cloud Skills Boost](https://cloudskillsboost.google/)

2026 年 7 月起，Google 新增了第三种续期路径——**完成指定的 Google Skills 课程或技能徽章**，认证有效期延长 1 年，免考试费：

- **哪些证可用**：Professional Cloud Architect、Professional Data Engineer、Associate Cloud Engineer、Cloud Digital Leader
- **核心规则**：只有在认证最后 12 个月内完成的课程/徽章记录才有效，提前完成不算
- **路径锁定**：PDE、ACE、CDL 一旦选定续期路径就不能在本周期内换；PCA 可以换路径
- **费用**：Google 目前未公布该路径的定价，部分课程在 Skills Boost 可免费访问

> 来源：[Google Cloud Changed How You Take and Renew Certifications in 2026](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)
