## 一、认证动态

### 1. AWS SAP-C03 & DVA-C03 同步开放注册：10月27日起报名，旧版最后窗口倒计时

**一句话**：AWS 两大主力认证同时换代，10月27日开注册、旧版 C02 分别在11月16日和11月30日停考，这周就要决定考旧还是考新。

AWS 在9月发布了年度认证更新公告，两张热门证书同步升版：

**Solutions Architect – Professional（SAP-C03）**

- 注册开放日：2026-10-27
- 正式开考（GA）日：2026-11-17
- 旧版 SAP-C02 最后可考日：2026-11-16
- 考试费：$300 USD | 时长：180 分钟 | 题目数：75 题
- 新版考点新增生成式 AI 架构决策与 Agentic 系统设计

**Developer Associate（DVA-C03）**

- 注册开放日：2026-10-27
- 正式开考（GA）日：2026-12-01
- 旧版 DVA-C02 最后可考日：2026-11-30
- 考试费：$150 USD | 时长：130 分钟 | 65 题（50 计分 + 15 测试题）
- 通过分：720/1000

两个版本变动的核心逻辑一致：AWS 把生成式 AI 和 Agent 开发的考点正式写入正式认证，而不是只放在 AI Practitioner 里。具体说，SAP-C03 会考多智能体系统架构，DVA-C03 新增 Amazon Bedrock Agents 调用和函数调用（tool use）集成。

**决策指南**：如果你备考超过1个月了、题库已刷熟，建议赶在10月27日前约考旧版——旧版题库市面上更多，短期胜率更高。如果还没开始备考，直接准备新版，毕竟旧版到11月底就停了，考完还能多几个月的有效期。

> 来源：[AWS Training and Certification Blog – September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 2. Anthropic Claude 四证体系全面上线：开发者首选 CCDV-F（$125），目前限 Partner 网络

**一句话**：Anthropic 在2026年把 Claude 认证扩展到四张，通过 Pearson VUE 正式发证，但目前只有 Claude Partner Network 成员公司的员工才能报考。

四张证书的定位与费用：

| 证书代号 | 全名 | 费用 | 适合谁 |
|---|---|---|---|
| CCAO-F | Claude Certified Associate, Foundations | $99 | 不写代码、用 Claude 做业务流程的运营/产品人员 |
| CCDV-F | Claude Certified Developer, Foundations | $125 | 用 Claude API / Claude Code / MCP 开发产品的工程师 |
| CCAR-F | Claude Certified Architect, Foundations | $125 | 设计 Claude 生产级应用架构的方案架构师 |
| CCAR-P | Claude Certified Architect, Professional | $175 | 设计并治理企业级 Claude 解决方案的高级架构师 |

四张证均为 120 分钟、通过分 720/1000、Pearson VUE 线下考，通过后在 Credly 颁发数字徽章，证书有效期 12 个月。

2026年6月30日起 CCAR-F 涨价（$99 → $125）并迁移到 Pearson VUE，此前考的证书有效期也从6个月延至12个月。截至今年6月，已有超过 10,000 名顾问拿到 Claude 认证。

**当前门槛**：报考必须是 Claude Partner Network 认证企业的在职员工，注册邮箱必须是企业域名邮箱，个人邮箱直接拒，非合作伙伴客户暂不开放。如果你在 AWS Partner / Google Partner 公司任职，可以去内部确认公司是否在 Anthropic Partner Network 里。

> 来源：[Training Camp – Claude Certifications Explained: All Four Anthropic Exams, Costs and Who Can Take Them](https://trainingcamp.com/articles/claude-certifications-explained-all-four-anthropic-exams-costs-and-who-can-take-them/)

### 3. AWS MLA-C02 Beta 已开考：机器学习工程师认证纳入 Gen AI，GA 日期 2027年1月14日

**一句话**：AWS Machine Learning Engineer – Associate 换代（MLA-C02），Beta 阶段只要 $75，正式版明年1月涨回正价，现在是最低门槛入场时机。

时间线：

- 英文 Beta 注册开放：2026-09-01
- MLA-C01 英文最后可考日：2026-09-28
- Beta 开始交付：2026-09-29
- 正式 GA（所有语言）：2027-01-14，届时 MLA-C01 退休

Beta 阶段规格：$75 USD | 170 分钟 | 85 题 | 仅英语

MLA-C02 新增考点围绕 Amazon Bedrock、Agentic AI 工作流和生成式模型微调，把机器学习工程师的职责范围从传统 SageMaker 训练流水线扩展到 LLM 应用交付。Beta 考试的题目会纳入最终正式版考纲，通过的人直接获得认证。

**注意**：Beta 名额通常有限，先到先得。MLA-C01 已经停考（9月28日截止），Beta 阶段是现在唯一能报的版本。

> 来源：[AWS Training and Certification Blog – September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 4. Azure DP-420 改名「Cosmos DB AI Developer Associate」：10月6日起生效，考点接轨 AI

**一句话**：原 Azure Cosmos DB Developer Specialty（DP-420）从10月6日起更名为 Azure Cosmos DB AI Developer Associate，考点增加了向量搜索和 AI 应用集成。

原 DP-420 的考试代码不变，名称里加入"AI Developer"反映了 Cosmos DB 在 RAG（检索增强生成）和向量索引场景中的广泛应用。已持有 DP-420 证书的人证书名称将自动更新，不需要补考。

考试费保持 $165 USD，专业级（Specialty）定位也维持不变。

> 来源：[Microsoft Certification Retirements 2026 – vladtalkstech.com](https://vladtalkstech.com/microsoft-learning-and-credential-news/microsoft-certification-retirements-2026/)

### 1. Anthropic × Coursera 上线 10 门全免费 AI 课：Claude Code 101、pK-12 教师专项均包含在内

**适合**：开发者、教育工作者、小企业主、创意工作者，纯小白也有对应入口
**链接**：[coursera.org（搜索 "Anthropic"）](https://www.coursera.org/courses?query=anthropic)

Anthropic 于2026年10月13日与 Coursera 联合发布了10门全免费课程，面向多个职业群体：

**开发者向**：
- **Claude Code 101**（2小时）：设置 Claude Code、委派任务、创建 subagent，快速上手 AI 辅助开发工作流
- **Claude Platform 101**：用 Claude API 和 agent loop 构建并上线产品
- **Introduction to Subagents**：哪些任务适合分给独立 agent、如何设计 agent 边界
- **Introduction to Agent Skills**：把重复提示词封装成可复用 skill 并在团队共享

**教育工作者向**（与 Teach for America / 美国教师联合会合作）：
- **AI Fluency for pK-12 Educators**（4小时）：用 AI 改编教材同时保护学生数据
- **AI Fluency for pK-12 Train the Trainer**：配合上面那门课的工作坊套件，含讲师指南和课堂练习

**通用入门**：
- **AI Capabilities and Limitations**（4小时）：AI 怎么生成答案、记忆机制、提示词如何影响输出
- **AI Fluency for Small Businesses**（4小时）：客服、供应链到市场营销的 AI 落地套路

全部10门课目前免费（不需要 Coursera Plus 订阅），Anthropic 表示后续每月会持续添加新课。

## 三、JR Academy 学员行动建议

1. **10月27日是关键节点**：AWS SAP-C03 和 DVA-C03 注册同日开放，同时 SAP-C02/DVA-C02 的最后考期倒计时也进入最后 30 天。本周确认自己的备考进度：已备考超2个月 → 赶旧版；刚开始或未开始 → 直接注册新版。

2. **在职于 Anthropic Partner 企业**：查一下公司是否在 Claude Partner Network，如果是，先考 CCDV-F（$125，120分钟，开发者入门首选），结合 Coursera 上的 Claude Code 101 和 Claude Platform 101 两门免费课备考，2-3周内完成没有问题。

3. **Data/AI 方向学员 → 刷 Hugging Face Agents Course**：全免费、有证书、覆盖 agent tool_call 到多 agent 编排，内容和目前 JR Data 课程的 AI Agent 模块高度互补，刷完能加一条有分量的 portfolio 项目。

4. **备考 AWS ML 认证**：MLA-C02 Beta 只要 $75（正式版会回到 $150），现在是进场成本最低的窗口。先在 AWS Skill Builder 免费层把 Machine Learning Fundamentals 路径刷完，再报 Beta 考。

5. **教育 / 培训方向学员**：Anthropic × Coursera 的 AI Fluency for pK-12 Educators（4小时）和 Train the Trainer 套件是目前市面上最系统的 K-12 AI 教学资源，拿下这个免费证书对申请澳洲教育技术类岗位有加分。
