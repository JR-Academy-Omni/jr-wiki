## 一、认证动态

### 1. Google Cloud Professional Agentic Architect — GA 本月中旬正式开考

**一句话**：这是 Google 迄今最新的 AI Agent 专项认证，beta 刚结束、GA 正式版本月内开放，现在备考节奏正好。

Google Cloud 官网认证页面现在直接写的是：**"Professional Agentic Architect GA exam will launch in mid-November — start preparing today!"**

这个认证和以往云计算证书不同，它分两阶段才算通关：

- **Part 1**：约 80 道多选题，3 小时，Pearson VUE 在线或现场监考
- **Part 2**：官网原话是 "If you pass the exam, you will receive instructions in CM Connect to take the distinct PAA hands-on labs in Google Skills to validate your execution and coding ability."

也就是说，光过笔试还不够，还要完成实操 Lab 才能拿徽章。Beta 阶段（9月8-30日）的候选人必须在 2026 年 12 月 31 日前完成 Labs，否则失效。

**考试定价**：$200 USD（beta 阶段打折价 $120 已结束），有效期 1 年（比大多数 AWS/Azure 认证的 3 年短），**无前置要求，推荐有 3 年以上云实操经验，含至少 1 年 Agentic 解决方案开发经验**。

对于想在 AI Agent 领域建立技术权威的工程师，这个认证性价比高——Google 云市场份额在涨，中文圈 PAA 持证者目前还是个位数。

> 来源：[Google Cloud Professional Agentic Architect 官方认证页](https://cloud.google.com/learn/certification/agentic-architect)

### 2. Microsoft Ignite 2026 旧金山站：在场免费考一门微软认证（11月16-20日）

**一句话**：本周末如果人在旧金山，这是年度最好的白嫖机会——持 Ignite 大会证件可免费考一门微软或 GitHub 认证。

Microsoft Learn 官方说明白了：**"In-person attendees can take one Microsoft or one GitHub certification exam free, onsite."**

具体安排：

- **地点**：Moscone Center West — Level 2, Room 2018, 747 Howard Street, San Francisco CA 94103
- **考试窗口**（官方原文）：**"The redemption window for this exam offer starts on November 16, 2026, and expires on November 20, 2026."**
- **考试时间段**：
  - 11月16日（周一）下午 1:00–5:00 PM
  - 11月17日（周二）下午 1:00–7:30 PM
  - 11月18日（周三）上午 8:30–下午 5:15 PM
  - 11月19日（周四）上午 9:00–下午 6:00 PM
  - 11月20日（周五）上午 9:00–12:15 PM

**可考科目**：官方列出的前缀全覆盖：AB、AI、AZ、DA、DP、MB、MD、MS、PL、SC，以及 GitHub 的 GH 系列。**所有非 beta 阶段的认证均可选**。

有意思的是官方还写了：**"No prerequisites are required to take an exam, but an individual certification might require prerequisites."** 意思是你可以直接报 AZ-305 甚至 AZ-700，不会被系统拦住，但要真的拿到徽章还是得先过 AZ-104。

现场可以走-up 注册，但名额有限，建议提前通过 Pearson VUE 预约。

> 来源：[Microsoft Ignite 2026 Onsite Certification Exam Registration Instructions](https://learn.microsoft.com/en-us/training/topics/ignite/microsoft-ignite-2026-certification-registration)

### 3. AWS CloudOps Engineer SOA-C03 — 简体中文 & 韩文版 11月19日退役

**一句话**：AWS 官网已明确写明本周三（11月19日）中韩双语版本截止，英语版继续正常考。

AWS 官方认证页原文：**"The exam in Simplified Chinese and Korean will be retired after November 19, 2026."**

CloudOps Engineer Associate（SOA-C03）是原来 SysOps Administrator 的更新版，2025年9月底正式替换 SOA-C02。主要变化：

- 新增 **ECS、EKS、ECR**（容器）以及 **CDK** 相关题目
- 考试代码从 SOA 系列延续，但证书正式名称改为 "CloudOps Engineer"
- **考试参数**：65题（50分计分题 + 15题不计分），130 分钟，$150 USD，720/1000 分通过

如果你正在备考中文版 SOA-C03，务必在本周三之前预约考试；11月20日起只有英文版可选。

> 来源：[AWS Certified CloudOps Engineer - Associate 官方页](https://aws.amazon.com/certification/certified-cloudops-engineer-associate/)

## 二、免费 / 限免课程

### 1. DeepLearning.AI — Evaluating and Improving Agentic Applications（11月4日上新）

**适合**：已经在做 LLM Agent 开发、想系统建立评测框架的工程师
**链接**：[deeplearning.ai — Evaluating and Improving Agentic Applications](https://www.deeplearning.ai/short-courses/evaluating-and-improving-agentic-applications/)

讲师是 Arize AI 的 Developer Relations 负责人 Laurie Voss，这家公司做的就是 LLM 可观测性工具，所以这门课的实操味道很强。

官方课程页说明：**"Build tests that show where your agent falls short, automate grading with code evaluators and validated LLM judges, and check whether each change is an improvement."**

课程结构：28 个视频、6 个代码示例、10 个评分作业，**总时长 15 小时 7 分钟**。涵盖：

- 用 Arize Phoenix 追踪 Agent 的 trace（模型调用 + 工具调用记录）
- 建立可复用 benchmark：给重复出现的 failure 打标签、持续加 test case
- 写 code evaluator 和 LLM judge，用 precision/recall/Cohen's kappa 量化评判可靠性
- 验证 tool call 顺序和任务完成率
- 把生产环境 failure 转化为回归测试

**价格**：视频内容免费观看；graded assignments + 证书需要 DeepLearning.AI PRO 订阅（$25/月按年付，$30/月按月付）。

AWS 官方博客在今年确认 Skill Builder 免费层现有 **220+ 免费 AI 课程**，从入门级到进阶的 Agentic AI 内容均有覆盖，不需要付费订阅。

### 3. Google Cloud Skills Boost — PAA 认证官方备考路径（免费预览）

**适合**：正在准备 Professional Agentic Architect 认证，或者想深入了解 Vertex AI Agent Builder 的工程师
**链接**：[Google Cloud Skills Boost](https://www.cloudskillsboost.google/)

Google Cloud Skills Boost 有针对 PAA 认证的学习路径，含 Qwiklabs 实操。部分内容可免费访问，全套 Lab 需要月度积分（通常 $29–49/月）。

鉴于 PAA 认证两部分必须都通过（笔试 + 实操 Lab），用 Skills Boost 做 Lab 练习是最对口的准备方式——考场上遇到的 Lab 和平台上的练习使用同一套 Google Skills 环境。

**时间敏感**：GA 在本月中旬开放，beta 候选人完成 Labs 的截止日期是 2026年12月31日。想从头开始备考的同学，现在到 GA 开放只有不到 2 周，主要先把笔试 Guide 刷完，实操留到后期。

### 4. Microsoft Learn — 为 Ignite 认证全程免费备考

**适合**：打算趁 Microsoft Ignite 旧金山考一门微软认证的参会者，或者远程备考下一门 Azure/AI 认证
**链接**：[Microsoft Learn Certifications](https://learn.microsoft.com/en-us/credentials/browse/?credential_types=certification)

Microsoft Learn 本身完全免费，不需要付费订阅——包括视频、互动模块、沙盒环境（免费层每月有配额）。真正花钱的只有考试本身（通常 $99–$165）。

考前选题建议：
- 参加 Ignite 现场，考 **AZ-900 Fundamentals** 是最稳妥的零基础选项（1–2 天速成）
- 有开发背景但没有 Azure 证书，考 **AZ-204**（Developer Associate）性价比最高
- 有安全背景，考 **SC-900** 或 **SC-200**
- 已有 Azure 基础，可以冲 **AZ-305**（Solutions Architect Expert）——Ignite 现场不会被前置卡住
