## 一、认证动态

### 1. Microsoft DP-700 Fabric Data Engineer 考纲 10 月 19 日刷新

**一句话**：Microsoft 官方认证页面于 10 月 19 日更新 DP-700 考纲，三大考域和考点同步调整，Study Guide 随之刷新，现在备考踩到最新版本。

DP-700（Microsoft Certified: Fabric Data Engineer Associate）是 Microsoft Fabric 数据工程师方向唯一的 Associate 级认证。本次更新覆盖三大考域：

1. **Implement and manage an analytics solution**（实施与管理分析解决方案）
2. **Ingest and transform data**（数据摄入与转换）
3. **Monitor and optimize an analytics solution**（监控与优化分析解决方案）

技能要求明确涵盖 SQL、PySpark 和 KQL（Kusto Query Language）。考试时长 100 分钟，通过 Pearson VUE 报名，支持 10 种语言（包括简体中文、繁体中文、日语）。

备考建议：官方 Study Guide 已同步更新，入口：[DP-700 Study Guide（Microsoft Learn）](https://aka.ms/DP700-StudyGuide)。认证页面还附有官方 Practice Assessment，报名前做一轮可以摸清题型分布。

续期机制：DP-700 认证到期前可通过 Microsoft Learn 免费在线评估续期，不需要重新参加正式考试。

> 来源：[Microsoft Certified: Fabric Data Engineer Associate – Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/fabric-data-engineer-associate/)（官方页面 `updated_at: 2026-10-19T20:48:00Z`）

### 2. AZ-500 已退役，SC-500 Cloud and AI Security Engineer 正式接棒

**一句话**：AZ-500（Azure Security Technologies）已于 2026 年 8 月 31 日正式退役，SC-500（Microsoft Certified: Cloud and AI Security Engineer Associate）自 7 月 21 日起接棒，AI 安全内容首次进入该认证考域。

这次更换的核心变化不只是改名——认证从"Azure Security Technologies"升级为"Cloud and AI Security Engineer"，代表微软把 AI 工作负载安全纳入了正式技术考核范围。

几个关键要点：

- 如果你已有 AZ-500 且还在有效期内，证书继续有效；但已无法再报名考 AZ-500，续期需转向 SC-500 路径
- SC-500 考纲覆盖范围：AI 工作负载安全、Microsoft Entra ID 身份治理、Microsoft Defender for Cloud、Microsoft Sentinel、Microsoft Purview
- 考试通过 Pearson VUE 报名，价格与其他 MS Associate 认证一致（因考试地区而异，澳洲约 AUD $250 左右，以官网为准）
- 一年有效期 + 免费在线续期机制沿用

SC-500 适合已过 SC-200（Security Operations Analyst）或 SC-300（Identity and Access）的学员，作为安全工程师路线的垂直深化。

> 来源：[Microsoft certification retirements 2026 – vladtalkstech.com](https://vladtalkstech.com/microsoft-learning-and-credential-news/microsoft-certification-retirements-2026/)；具体考纲和报名请前往官方页面核查：[learn.microsoft.com – SC-500](https://learn.microsoft.com/en-us/credentials/certifications/azure-security-engineer/)

### 3. Office LTSC 2021 支持于 10 月 13 日终止：IT 管理员的迁移时间窗口开启

**一句话**：Office Long Term Servicing Channel（LTSC）2021、Project LTSC 2021 和 Visio LTSC 2021 均于 10 月 13 日到达支持终止日期，微软不再提供安全更新、功能更新和技术支持。

来自 Microsoft Partner Center 的官方公告原文："Support for Office Long Term Servicing Channel (LTSC) 2021, Project LTSC 2021, and Visio LTSC 2021 ended on October 13, 2026."

继续使用 LTSC 2021 的实际风险：

- 安全漏洞得不到 patch，可能引发合规问题（尤其 GRC 合规方向的学员要注意）
- 无法使用 Microsoft Copilot（Copilot 仅支持云端 Microsoft 365 订阅版）
- 微软不再提供技术支持

微软官方推荐的升级路径：

| 用户规模 | 推荐路径 |
|---------|---------|
| 企业用户（300+席位） | Microsoft 365 E3（首选）|
| 中小企业（< 300 席位） | Microsoft 365 Business Premium |
| 离线/受监管行业 | Office LTSC 2024（含最新安全支持）|

对证书备考的连带影响：MS-102 续 AB-650、AZ-104（Azure Admin）和 M365 管理员系列的迁移场景考题中，LTSC 到 M365 的迁移评估越来越频繁出现。

> 来源：[Microsoft Partner Center October 2026 Announcements – learn.microsoft.com](https://learn.microsoft.com/en-us/partner-center/announcements/2026-october)（原文："Support for Office Long Term Servicing Channel (LTSC) 2021, Project LTSC 2021, and Visio LTSC 2021 ended on October 13, 2026."）

## 二、免费 / 限免课程

### 1. Hugging Face Learn：12 门全免费课，Agents Course + Context Course 是本周重点

**适合**：想学 AI Agent 开发、LLM 微调、Transformer 应用的学员，零费用直接开始
**链接**：[huggingface.co/learn](https://huggingface.co/learn)

Hugging Face Learn 官方页面目前有 12 门课程，全部完全免费，无需注册或付费即可开始学习。

以下 5 门对 JR 学员当前阶段最实用：

**1. Agents Course** — "Building and deploying AI agents"
从零实现一个完整 AI agent：工具调用、记忆管理、多轮对话。对应 AWS Bedrock Agents / Azure AI Agent Service 的开源替代实现路径，学完能看懂主流 agentic framework 的代码结构。

**2. Context Course** — "Context engineering for code agents"
专门讲如何给代码 agent 提供更好的上下文（context window 管理、工具描述设计、prompt 结构化）。这是今年 AI 工程里最实用的方向之一，LLM 用得好不好，70% 取决于 context 设计。

**3. LLM Course** — "Large language models using HF ecosystem libraries"
用 Hugging Face 生态（transformers、datasets、tokenizers）完整走一遍 LLM 训练 / 微调 / 推理流程。是进入 ML Engineer 方向的标准入门路线。

**4. a smol course** — "A short course on post-training AI models"
专注 post-training 环节：指令微调（SFT）、对齐（RLHF、DPO）、量化。格式短，1-2 周可以过完，适合已经了解 LLM 基础的学员。

**5. Deep RL Course** — "Deep reinforcement learning using HF ecosystem libraries"
覆盖 PPO、DQN 等主流 RL 算法，适合想走 AI 研究或 robotics 方向的学员。

> 来源：[Hugging Face Learn – huggingface.co/learn](https://huggingface.co/learn)（官方页面列出 12 门课程，含 Agents Course、Context Course、LLM Course 等名称描述）

### 2. DeepLearning.AI × JetBrains：Spec-Driven Development with Coding Agents（1h16m，视频免费）

**适合**：已经会一门编程语言、想用 AI agent 提升开发效率的学员
**链接**：[deeplearning.ai/courses](https://www.deeplearning.ai/courses)

DeepLearning.AI 近期与 JetBrains 合作上架的 Spec-Driven Development with Coding Agents 课程时长 1 小时 16 分钟，初级定位，核心思路是：**先写"规格（specification）"，再让 coding agent 根据规格生成代码**。

这个流程解决了直接让 AI agent 写代码容易"跑偏"的问题——agent 按着写好的规格执行，错误更可查、更可改。适合 JetBrains 工具链（PyCharm、IntelliJ IDEA 等）用户对接 AI agent 工作流。

关键信息：
- **视频免费**：短课视频内容完全免费观看，不需要账号付费
- **实验和证书**：需要 DeepLearning.AI Pro 会员（$25/月，按年付）

同期其他值得看的免费视频课：
- **Document AI: From OCR to Agentic Doc Extraction**（与 LandingAI 合作，3h11m，中级）—— 从传统 OCR 到 agentic 文档提取，适合做文档自动化处理的同学
- **Transformers in Practice**（与 AMD 合作，11h，中级）—— 系统性理解 Transformer 架构，比只看应用层更扎实

> 来源：[DeepLearning.AI Courses – deeplearning.ai/courses](https://www.deeplearning.ai/courses)（课程列表包含 "Spec-Driven Development with Coding Agents, Partner: JetBrains, Duration: 1h16m, Level: Beginner"）

### 3. Harvard CS50x：完成作业免费领 CS50 Certificate，无需走 edX 付费通道

**适合**：想打扎实 CS 基础、没有 CS 学位但想要一个有说服力证书的学员
**链接**：[cs50.harvard.edu/x](https://cs50.harvard.edu/x)

CS50x 是哈佛大学计算机科学入门课，但有一个很多人不知道的关键点：**CS50 Certificate 由哈佛 CS50 团队直接颁发，完全免费**，和 edX 的付费 verified certificate 是两条独立的通道。

官方 FAQ 原文："a CS50 Certificate is a free certificate from CS50 itself"。

领取条件：每个 Problem Set、Lab、和最终 Final Project 均达到 70 分以上。课程自学节奏不限，全年随时开始。

内容覆盖：C 语言基础 → Python → SQL → JavaScript/TypeScript → 网络编程 → AI 入门（最后一周）。对于准备备考 AWS Solutions Architect Professional 或 Azure Solutions Architect Expert 的学员，CS50x 里的网络、OS、数据库基础能填补一些考题里的底层盲区。

注意：edX 平台上另有一个"edX verified certificate"大约 $300，那是 edX 平台自己的付费通道，不是免费的 CS50 Certificate，不要搞混。

> 来源：[CS50x 2026 FAQ – cs50.harvard.edu/x/faqs](https://cs50.harvard.edu/x/faqs/)（"a CS50 Certificate is a free certificate from CS50 itself"）

## 三、JR Academy 学员行动建议

1. **Microsoft Fabric 方向**：DP-700 考纲 10 月 19 日刚更新，Study Guide 同步刷新，现在下手拿到最新版考纲。Fabric 在澳洲、新加坡的企业数据项目里 job spec 提到频率明显上升，DP-700 比已退役的 DP-203 更贴近当前实际需求。

2. **Azure 安全方向**：如果你之前在备 AZ-500，直接切到 SC-500（Cloud and AI Security Engineer）——旧考纲已作废，新考纲加了 AI 安全内容，正好对应市场上"Azure Security Engineer + AI"复合技能的 job spec。

3. **Office LTSC 迁移项目**：如果你在 IT Support / Sysadmin 岗，现在是向管理层汇报"Office LTSC 2021 已无安全 patch"的时机，推动迁移到 M365 E3 或 Business Premium。这类迁移项目能带来 Entra ID、Intune、Defender 的实战经验，直接对应 M365 管理员系列认证的考点。

4. **AI 编程技能**：3-4 小时快速充电路径：先看 DeepLearning.AI × JetBrains 的 Spec-Driven Development（1h16m，免费视频），再进 Hugging Face Learn 的 Context Course 打深度。两门课学完对 AI agent 工作流会有完整认知框架，之后更容易接上 JR Academy AWS Bedrock 或 Azure AI 实战课。

5. **CS 基础补课**：准备冲 SAP-C03（AWS Solutions Architect Professional）或 AZ-305（Azure Solutions Architect Expert）的学员，如果觉得网络 / OS / 数据库底层薄弱，CS50x 是零成本的铺垫选项。结课后申领免费 CS50 Certificate，简历上也是加分项。
