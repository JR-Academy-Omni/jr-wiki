## 一、认证动态

### 1. AWS ANS-C01 高级网络认证：12月31日截止，退场后无替代

**一句话**：AWS 官方认证页面确认，Advanced Networking Specialty（ANS-C01）最后一天考试为 2026年12月31日，之后 AWS 认证体系里将没有独立的网络方向专项认证。

这是一个容易被误算时间的倒计时。ANS-C01 原本计划 2026年8月25日退场，但 AWS 在社区反馈后把截止日推到了 12月31日。很多人以为"已经退场了"，实际上还有将近 60 天可以报考。

关键细节：AWS **没有宣布任何替代认证**。ANS-C01 下架后，AWS 官方认证路径里不再有专门针对高级网络的认证选项。对于已经考过的人，三年有效期按正常规则计算，不受退场影响。对于在犹豫要不要考的人，这次真的是最后一次了。

备考建议：AWS Skill Builder 上有对应的免费数字课程（无需订阅），可以用来摸底知识缺口。

> 来源：[AWS 官方认证页面](https://aws.amazon.com/certification/)；[certcrush.app ANS-C01 退场分析](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026)

---

### 2. AWS DVA-C03 (Developer Associate 新版) 报名已开放，本月底是老版 DVA-C02 最后机会

**一句话**：AWS 于 10月27日官方宣布 DVA-C03 报名开放，12月1日正式开考；DVA-C02 11月30日永久退场，本月底前还能考老版。

DVA-C03 和 SAP-C03 是 AWS 今年最重要的两次更新版本同步上线事件。SAP-C03 昨天（11月3日）已正式开考，DVA-C03 还有 27 天窗口。

两个选择供参考：
- **现在报 DVA-C02**：题库和备考材料更成熟，价格相同，12月前完成考试就行。
- **等 DVA-C03**：从 12月1日开考起，这是唯一选项；新版更聚焦 AI 相关服务集成，对想长期使用这张证书的人更有价值。

DVA-C03 的 exam guide 已经可以从 AWS 认证页面下载，建议现在就对比和现有备考材料的差异。

> 来源：[AWS Training and Certification Blog，2026年10月27日](https://aws.amazon.com/blogs/training-and-certification/)

### 3. CKA/CKAD/CKS 11月折扣码：DCUBE30，$445 单科折后约 $311

**一句话**：Linux Foundation 的三门 Kubernetes 认证（CKA、CKAD、CKS）目前均有折扣，代码 DCUBE30 可省约 30%，单科考试原价 $445。

具体情况：

| 认证 | 原价 | DCUBE30 后（约） |
|------|------|-----------------|
| CKA | $445 | ~$311 |
| CKAD | $445 | ~$311 |
| CKS | $445 | ~$311 |

套餐有更大折扣：CKA + CKS 组合用代码 DCUBEOFFER 叠加有额外 15% 优惠，具体结算价以 Linux Foundation 结账页为准。

注意：折扣码从第三方整理页面收集，使用前在结账页确认折扣是否生效。Linux Foundation 官方结账页不受该站控制。

> 来源：[devopscube.com Kubernetes 认证折扣汇总（2026年11月）](https://devopscube.com/kubernetes-certification-coupon)

### 4. AWS Certified AI Business Strategist (AIB-C01) Beta 仍在开放

**一句话**：AWS 推出的非技术向 AI 商业策略认证 Beta 仍可报名，Beta 阶段通过可拿 Early Adopter Badge。

AIB-C01 面向评估和推动 AI 战略落地的商务人员，不测写代码，考核方向包括：AI 项目评估框架、AI 风险与治理、AI 商业案例设计。对 IT 管理层、产品经理、咨询顾问群体更相关。

Beta 阶段的好处：Beta 价格通常比正式版低，且先过 Beta 的候选人在证书上有 Early Adopter 标记。

> 来源：[AWS 官方认证页面](https://aws.amazon.com/certification/)

## 二、免费 / 限免课程

### 1. Snowflake Practitioner：官方全免费，含 30 天实操环境

**适合**：数据分析师、数据工程师、平台管理员中任何一个想系统学 Snowflake 操作的人
**链接**：[Snowflake 官网培训页](https://www.snowflake.com/en/learn/training/)

Snowflake 新推出的 Practitioner 基础课全面免费，这是官方主动移除了入门级培训费用后的结果。课程结构：

- **Day 1（所有人共同）**：Snowflake 平台架构、核心概念导入
- **Day 2（按角色分流）**：
  - 数据分析师：查询、报表、数据可视化
  - 数据工程师：管道搭建、数据加载、数据转换
  - 平台管理员：安全配置、角色管理、访问控制、成本监控

亮点是 30 天的动手实验室环境——不是看视频，是真正在 Snowflake 上操作。课程形式支持公开场次直播、企业内部私人场次、以及自学录播，三种方式都免费。

关于证书：Practitioner 本身不含结业证书，课程定位是通往 SnowPro Core 认证（COF-C03）的准备阶段。SnowPro Core 考试另行付费。

> 来源：[itbrief.com.au — Snowflake launches free AI data training for users](https://itbrief.com.au/story/snowflake-launches-free-ai-data-training-for-users)

### 2. DeepLearning.AI "Loop Engineering with LangChain Deep Agents"（最新上架）

**适合**：已经用过 LangChain 或基础 Agent 框架，想深入 Agentic Loop 控制机制的工程师
**链接**：[deeplearning.ai/short-courses/](https://www.deeplearning.ai/short-courses/)

DeepLearning.AI 本周在"Just Added"区上架的最新短课，时长 1 小时 16 分，Intermediate 难度。围绕 LangChain 的深层 Agent 循环工程展开，不是简单的 "how to chain prompts"，而是讲 Loop 控制、状态管理和工具调用设计。

费用说明：**视频内容免费**，但带评分的 lab 和结业证书需要 DeepLearning.AI Pro（$25/月按年计费）。如果只是想看知识内容，直接免费看视频即可。

### 3. DeepLearning.AI "Building Adaptive AI Agents" — Oracle 团队讲 Agent 自适应三层架构

**适合**：在生产环境部署过 Agent 但遇到行为固化、上下文管理问题的工程师
**链接**：[deeplearning.ai/courses/building-adaptive-ai-agents/](https://www.deeplearning.ai/courses/building-adaptive-ai-agents/)

讲师：Oracle AI Developer Advocate Nacho Martínez 和 Casius Lee。时长 1 小时 3 分，7 个视频课 + 3 个代码示例。

课程核心是三个自适应层：
1. **行为层（Behavior）**：把 Agent 的 traces（工具调用链、错误、修复记录）转为可复用 skill，每个 skill 经人工审批后入库
2. **知识层（Knowledge）**：从代码库的 import 关系、函数调用链、git co-edit 历史构建知识图谱，用于检索上下文，对比纯关键词/正则搜索效果更好
3. **模型层（Model）**：判断什么情况下适合微调模型本身，而不只是调提示词

费用说明同上：**视频免费，Lab + 证书需要 Pro 订阅**。

> 来源：[deeplearning.ai/courses/building-adaptive-ai-agents/](https://www.deeplearning.ai/courses/building-adaptive-ai-agents/)

### 4. Hugging Face Context Course：上下文工程，免费且有免费证书

**适合**：在开发代码 Agent 或 AI 助手时遇到上下文管理问题的工程师
**链接**：[huggingface.co/learn](https://huggingface.co/learn)

Hugging Face 官方课程库目前有 12 门课，均完全免费，部分课程提供免费证书（如 Agents Course）。最近新增的 **Context Course** 专注于"上下文工程"（Context Engineering）——给代码 Agent 准备和注入正确上下文信息的系统方法，这是决定代码 Agent 输出质量的关键环节之一。

在 Hugging Face 课程页面，每门课的完整视频、练习和社区讨论均免费访问，不需要注册也不需要信用卡。

> 来源：[huggingface.co/learn](https://huggingface.co/learn)
