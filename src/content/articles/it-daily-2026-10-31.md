## 一、认证动态

### 1. AZ-401 Agentic DevOps Engineer Expert Beta：前300名8折，11月9日截止

**一句话**：Microsoft 新出的 AZ-401 Beta 考试对首批300名候选人提供80%折扣，窗口只剩9天，之后按正常价（一般 $165）。

微软于2026年10月15日宣布 **Microsoft Certified: Agentic DevOps Engineer Expert** 认证，配套考试 AZ-401《Designing and Implementing Microsoft Agentic DevOps Solutions》目前处于 Beta 阶段。

Beta 折扣：**前300名在 2026年11月9日前参考**可获得80%折扣，折后约合 $33（正式版价格尚未公布，参考 AZ-400 定价约 $165，不含税）。折扣不适用于土耳其、巴基斯坦、印度、中国大陆。

**考试内容变了什么**：AZ-401 把"Agentic"放进了核心——GitHub Copilot 驱动的流水线、Azure DevOps + AI 代理自动化、YAML/KQL/Bicep 实操——而不是传统的人工 CI/CD 流程调优。

**获得这个证书需要**：AZ-401 考过 **+** GH-300（GitHub Copilot）或 AZ-104（Azure Administrator）二选一。如果你已经持有 AZ-104，只需要补考 AZ-401 就能拿到新认证。

**关于 AZ-400 的去留**：Microsoft TechCommunity 官方博客公告（2026-10-15）表明 AZ-400 和 DevOps Engineer Expert 将于 **2027年2月1日** 退场。微软官方 AZ-400 考试页面（2026-10-30 更新）暂时还未反映退场日期，但 Beta 公告已确认。有意拿老证书的，最晚 1 月底前出考场。

> 来源：[Microsoft Community Hub - New Microsoft Certified: Agentic DevOps Engineer Expert](https://nisalgunawardhana.com/blog/microsoft-certified-agentic-devops-engineer-expert)

### 2. AWS ANS-C01 Advanced Networking Specialty：12月31日永久退场，无替代考试

**一句话**：AWS Advanced Networking Specialty 最后一次考试日是2026年12月31日，没有继任版本，今天（10月31日）起只剩61天。

AWS Certified Advanced Networking – Specialty（ANS-C01）是 AWS 专项认证里技术含量最高的一张，覆盖 VPC 深度架构、Transit Gateway、Direct Connect、Route 53 复杂路由、混合云网络等。2026年8月原定退场，经候选人反馈后推迟至 **12月31日**，但这是最终期限。

几个关键数字：
- **考试费 $300**，Pearson VUE 全球重考优惠**不适用于此考**
- 重考等待期为14天，所以最晚**12月10日**出考场，才有一次补考机会
- 已持有证书的人，认证有效期为正常3年，届满后无法再续（无继任版本）
- AWS Skill Builder 上的网络方向课程仍然保留，但不会产出新认证

AWS 官方表态未来网络技术会整合进 Solutions Architect Professional 和 Security Specialty 考纲，而不是单独出一门新的网络专项。换句话说，**ANS-C01 这张牌已经是最后一版**。

目前距离12月31日还有约8到12周学习周期——如果你已经在网络方向做了一年以上实操，刷完题后抓紧报考；如果刚起步，时间较紧，可以把精力投到 SAA-C03 和 Security Specialty 方向。

> 来源：[cloudninja.pro - ANS-C01 Retirement: Last Exam Date and What To Do](https://cloudninja.pro/blog/ans-c01-retirement)

### 3. AWS MLA-C02 Beta 仍在进行：$75 享受半价，GA 日期 2027年1月14日

**一句话**：AWS Machine Learning Engineer Associate 更新版 MLA-C02 Beta 已在运行中，$75 的 Beta 价格比 GA 版本（$150）便宜一半。

MLA-C02 Beta 于2026年9月29日开始交付（注册从9月1日开放），正式版计划 **2027年1月14日** 全语种上线。目前的 Beta 考试代码为 ME1-C02，GA 后改为 MLA-C02。

- **Beta 价格**：$75 USD
- **题目数量**：85题，170分钟
- **MLA-C01 已退出英文版**：C01 英文版最后考试日为9月28日，日韩中版在 Beta 期间保留
- **内容变化**：新增 Generative AI / Agentic AI / Foundation Model 工作负载，删除 SageMaker Neo edge 和自带容器的 SageMaker 内容

注意：Beta 期间**不出分，只给通过/未通过**。GA 后才会有分数报告。如果你想攒一张 ML 工程师认证又不想花全价，这个窗口值得进。AWS 已证实 GA 日期为1月14日，但实际可报名节点以 Pearson VUE 系统为准。

> 来源：[AWS Training and Certification Blog - September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 4. Microsoft AB-400：Power Platform Developer 考试从10月16日起换新代码

**一句话**：PL-400 已于10月16日正式切换为 AB-400，考试内容精简为4个域，旧代码不再接受注册。

Microsoft Power Platform Developer Associate 认证对应考试从 **PL-400** 更名为 **AB-400**（Extending Microsoft Power Platform Solutions with Code and AI），自2026年10月16日起生效。证书本身没变——依然是 Power Platform Developer Associate——但考试代码换了，学习路径做了调整：

- 旧 PL-400：6个考试域
- 新 AB-400：4个考试域，把设计部分并入更宽泛的"构建解决方案"模块，并加入了 AI 功能相关内容

如果你的备考材料是旧版 PL-400 的，建议对照 Microsoft Learn 上 AB-400 最新 skills outline 做差异检查，特别是新加入的 AI 扩展部分。

> 来源：[Microsoft TechCommunity - Updates to Azure Cosmos DB and Power Platform Developer](https://techcommunity.microsoft.com/t5/the-skills-hub-blog/updates-to-azure-cosmos-db-and-power-platform-developer/ba-p/4528353)

## 二、免费 / 限免课程

### 1. Hugging Face AI Agents Course（完全免费，含官方证书）

**适合**：会 Python 基础、用过 LLM API、想系统学 AI agent 开发框架的开发者
**链接**：[huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course/unit0/introduction)

Hugging Face 官方出品的 AI Agents Course，覆盖从理论到落地的完整路径：

- **框架覆盖**：smolagents（Hugging Face 自研轻量 agent 框架）、LangGraph、LlamaIndex
- **内容设计**：每章约3-4小时，没有截止日期，随时开始
- **证书选项**：
  - 完成 Unit 1 → **Fundamentals Certificate**（免费）
  - 完成 Unit 1 + 一个 use case 作业 + 最终挑战 → **Certificate of Completion**（免费）
- **额外福利**：完成的 agent 可以发布到 Hugging Face Hub 和 Spaces，有实际可展示的作品

2026年10月 DEV Community 的一篇验证文章特别提到了其中的 **MCP 课程模块**——这个模块由 Hugging Face 和 Anthropic 合作开发，讲的是 Model Context Protocol 的原理和在 agent 工作流里的用法。对关注 Claude API 生态的开发者有参考价值。

对 JR Academy 学员来说，这门课是目前最完整的免费 AI agent 工程路径之一，拿证成本为零，学完能直接写进 portfolio。

## 三、JR Academy 学员行动建议

1. **AZ-401 Beta 8折倒计时9天**：如果你已经有 AZ-104 或 GH-300，现在注册 AZ-401 Beta，在11月9日前参考，享受约80%折扣（$33 vs 正式版 ~$165）。Beta 考完 ~10天出成绩，12月拿到 GA 版本就正式持证上岗。去 Microsoft Learn 搜"AZ-401"报名。

2. **ANS-C01 最后报考窗口**：如果你已经在学 AWS 网络方向满6个月以上，刷完 [Tutorials Dojo 的 ANS-C01 练习题](https://tutorialsdojo.com) 后，最晚12月10日参加第一次考试——如果没过，还有一次 12 月底的机会。低于70%模考通过率就先别报。

4. **Hugging Face AI Agents Course 本周开始**：这门课免费拿证，不卡时间。本周先完成 Unit 1（3-4小时）就能拿 Fundamentals Certificate，之后按自己节奏继续。做完 MCP 模块后，你对 Claude API + agent 工作流会有直接的工程认知。

5. **AWS Skill Builder 10个 Labs**：正在备考 CLF-C02 或 SAA-C03 的学员，把那10个免费 Builder Labs 全刷一遍——EC2、IAM、Lambda、VPC 都是必考服务，考前一周做一遍比纯看视频记得牢。
