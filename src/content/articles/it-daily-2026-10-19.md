## 一、认证动态

### 1. AWS MLA-C02 Beta 开考：$75 拿新版机器学习工程师认证

**一句话**：AWS ML Engineer Associate 新版（MLA-C02）已于 9 月 29 日进入 Beta 阶段，限时 $75 考费，较正式版便宜约一半。

AWS 官方博客（September 2026 Certification Updates）确认：

- MLA-C02 Beta 于 **2026 年 9 月 29 日** 开始交付（英文），170 分钟，85 题，**Beta 价格 $75**
- 旧版 MLA-C01 英文考场已于 9 月 28 日关闭
- GA 正式版全语言交付时间：**2027 年 1 月 14 日**；届时 MLA-C01 同步退休

新版 MLA-C02 增加了**生成式 AI、Agentic AI 及基础模型/LLM** 覆盖，原有四个考试域结构不变，但各域内容已加入 Amazon Bedrock 和 AI 安全相关任务。对准备冲 ML 方向的同学，现在 $75 拿 Beta 是最经济的窗口，正式版定价大概率回到 $150+。

考试通过评分逻辑：Beta 阶段成绩不当场出，等 AWS 完成标准化后几周内发邮件通知。

> 来源：[AWS Training and Certification Blog — September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 2. Azure AI 新三板斧定价出炉：AI-901 $99、AI-103 / AI-300 各 $165

**一句话**：微软今年 6 月用 AI-901/AI-103/AI-300 替换了 AI-900/AI-102/DP-100，10 月份官方考试页面已确认三项新考价格。

根据 10 月 6 日检查的 Microsoft Learn 认证页面数据：

| 新考试代码 | 替换原考 | 定价（美国） |
|---|---|---|
| AI-901（AI Fundamentals） | AI-900 | **$99** |
| AI-103（Azure AI Engineer） | AI-102 | **$165** |
| AI-300（Azure Data Science） | DP-100 | **$165** |

三项均在 2026 年 6 月完成切换，新版考题大幅加入 Azure OpenAI Service、Copilot Studio 和 Azure AI Foundry 内容。Associate/Expert/Specialty 级别认证有效期 **1 年，到期免费在线续期**；Fundamentals 不过期。

对于 JR 学员的建议：AI-901 $99 是 Azure AI 路径的入门垫脚石，建议拿完再备 AI-103（助理级），路径清晰。

> 来源：[Microsoft Certification Retirements 2026 — vladtalkstech.com](https://vladtalkstech.com/microsoft-learning-and-credential-news/microsoft-certification-retirements-2026/)

### 3. Google Cloud GEAR 第三期：ACE/PCA/GAIL 三轨 10 月 12 日开班

**一句话**：Google Cloud GEAR（Get Certified）第三期 10 月 12 日正式开课，免费发放考试 Voucher，需公司企业邮箱报名（申请窗口已于 9 月 16 日关闭）。

本期三个认证轨道：

- **Associate Cloud Engineer（ACE）**：9 周，覆盖应用部署与云运维，提供英文、西班牙文（拉丁美洲）、葡萄牙文（巴西）版本
- **Professional Cloud Architect（PCA）**：6–9 周；持有 AWS 或 Azure 认证者可选 6 周加速班
- **Generative AI Leader（GAIL）**：5 周，面向希望推动 AI 落地的管理层

每周要求投入 **不少于 9 小时**，完成里程碑后 Google 免费发放考试 Voucher。本期报名在 9 月 16 日截止，下期预计 2027 年初开放。

如果你是 Google Cloud 客户公司的员工，现在可以通过企业邮箱注册 GEAR 门户，提前占好席位等下期报名通知。

> 来源：[GEAR Get Certified: Google Cloud's Free Certification Program — techbytes.app](https://techbytes.app/posts/google-cloud-gear-program-free-certification-2026/)

## 二、免费 / 限免课程

### 1. Anthropic 上线 10 门 Coursera 免费课：Claude Code 101 + 教师 AI 教学包全套

**适合**：开发者 / 产品经理 / 教师 / 小企业主
**链接**：[coursera.org/learn/claude-code-101](https://www.coursera.org/learn/claude-code-101)

Anthropic 于 **10 月 13 日** 向 Coursera 追加 10 门课，将课程目录从 12 门扩充至 22 门，**全部免费**，后续每月持续上新。

开发者向重点课程：

- **Claude Code 101**：约 2 小时，零基础可上手，覆盖安装配置、explore→plan→code→commit 工作流、CLAUDE.md 定制和子 Agent 设计。免费，无证书。
- **Claude Platform 101**：API 和 agent loop 产品化实战，适合想上线 AI 功能的工程师
- **Introduction to Subagents**：什么任务该分给独立 Agent、怎么设计协作逻辑
- **Introduction to Agent Skills**：用可复用 Skill 替代反复写提示词，包含团队共享方案
- **AI Capabilities and Limitations**：4 小时，讲清楚 AI 如何生成答案、记忆上下文、提示词怎样影响输出

教育从业者向：

- **AI Fluency for pK-12 Educators**（与 Teach for America 合作）：4 小时，教 AI 辅助备课的同时保护学生数据
- **AI Fluency for pK-12 Train the Trainer**（与 AFT 合作）：提供完整工作坊套件（PPT + 讲师指南 + 按年级分组练习），面向需要在学校内部推广 AI 培训的老师

> 来源：[Anthropic brings 10 free AI courses to Coursera — EdTech Innovation Hub](https://www.edtechinnovationhub.com/news/anthropic-brings-10-free-ai-courses-to-coursera-including-training-for-teachers)

### 2. Hugging Face MCP Course：从零掌握 Model Context Protocol，全程免费

**适合**：想搞明白 AI Agent 怎么调外部工具的开发者
**链接**：[huggingface.co/learn/mcp-course](https://huggingface.co/learn/mcp-course/en/unit0/introduction)

Model Context Protocol（MCP）是 Anthropic 发布的开放标准，让 AI 模型能标准化接入外部数据源和工具，是当前 Agent 开发的基础设施层。

课程结构：

- Chapter 0：入门与环境搭建（1 周，约 3-4 小时）
- Chapter 1：MCP 基础原理与架构
- Chapter 2-3：构建并部署一个完整的 MCP 应用
- Chapter 4：Bonus 进阶单元

**认证完全免费**，完成即发课程证书。截至 2026 年中，Hugging Face Agents Course（同系列）已颁发逾 20 万张证书，MCP Course 沿用同一机制。

对于已经会写 Python 的同学，4 周学完 MCP 是当前 Agent 生态中投入产出比最高的学习项目之一。

> 来源：[Hugging Face MCP Course](https://huggingface.co/learn/mcp-course/en/unit0/introduction)

### 3. AWS Skill Builder 免费层：600+ 数字课程，无需绑定信用卡

**适合**：准备 AWS 认证的初学者
**链接**：[skillbuilder.aws](https://skillbuilder.aws)

AWS Skill Builder 免费层（Individual Plan）提供 **600 余门** 数字课程，覆盖云计算基础、生成式 AI、机器学习、安全和数据分析。无信用卡要求，邮箱注册直接访问。

需要注意的是：**实验环境（Cloud Quest Lab、Simulation Lab）和部分模拟考题需要付费订阅**（Team Subscription，约 $449/年/人）。纯刷视频和官方讲义走免费层完全够用。

对准备 MLA-C02 Beta 的同学，Skill Builder 上有专项备考路径 Machine Learning Engineer – Associate，建议优先刷完再报 Beta 考场。

> 来源：[AWS Skill Builder 官方页面](https://skillbuilder.aws)

## 三、JR Academy 学员行动建议

1. **AWS ML 方向，本周内订好 MLA-C02 Beta 考场**。Beta 价 $75，通过即为正式证书，1 月 14 日 GA 后补考要 $150+。考试域无变化，用 MLA-C01 备考材料加刷 Bedrock/LLM 章节够用。

2. **Azure AI 路径，先搞定 AI-901（$99）再备 AI-103（$165）**。两考合计 $264，性价比优于同时报三门。AI-901 已有 JR Academy Azure 入门视频对应，学完直接约考。

3. **本周抽 2 小时上完 Claude Code 101**（Anthropic Coursera 免费课）。不需要证书，但工作流本身直接用于日常开发提效，特别是 CLAUDE.md 定制和子 Agent 章节。

4. **Google Cloud 方向，现在进 GEAR 门户注册企业邮箱**（developers.google.com/program/gear/getcertified），等第四期开放报名第一时间提交，先到先得审核。

5. **想学 MCP / Agent 开发，直接开 Hugging Face MCP Course Chapter 0**。不用等，现在开学 4 周可拿完整免费证书，比看零散教程系统得多。
