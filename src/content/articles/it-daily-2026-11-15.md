## 一、认证动态

### 1. AWS SAP-C02 明天是最后一天，SAP-C03 后天正式开考

**一句话**：11月16日是 Solutions Architect Professional SAP-C02 最后考试日，错过就要等 SAP-C03 考纲重新备考。

SAP-C02 已经服役多年，AWS 在今年9月的官方博客里明确宣布退役时间：

> "The last day to take the current version of the exam (SAP-C02) will be November 16, 2026."

后天（11月17日），更新版本 SAP-C03 正式开始交付。SAP-C03 注册通道已于10月27日开放（所有语言同步），新版增加了 AI/ML 集成和 Well-Architected 框架的权重，整体难度评估略有上升。

**如果你已经备考 SAP-C02 超过8成**：今晚登 Pearson VUE 或 PSI，抢最后时段。如果你只备了5成不到，不建议硬冲——SAP-C03 的 exam guide 已公开，可以系统重来。

> 来源：[AWS Training and Certification Blog – September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

---

### 2. AWS DVA-C02 月底退役，DVA-C03 新版接档

**一句话**：Developer Associate 老版 DVA-C02 11月30日停考，12月1日起只能考 DVA-C03。

同一批 AWS 认证更新里，Developer Associate 也换代了：

> "The last day to take the current version of the exam (DVA-C02) will be November 30, 2026. GA delivery [for DVA-C03] beginning December 1, 2026."

DVA-C03 新增了 Lambda 新 runtime、Step Functions 和 Bedrock API 集成内容，对比 DVA-C02 加重了"无服务器架构 + AI 功能调用"模块。已经在刷 DVA-C02 题库的同学，本月内安排上考场是最优解——题库不用换、备考时间不白费。

> 来源：[AWS Training and Certification Blog – September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

---

### 3. AWS ANS-C01 年底退役，官方不设替代证书

**一句话**：Advanced Networking Specialty ANS-C01 将在12月31日退役，AWS 明确表示不会出 ANS-C02。

> "ANS-C01 retires December 31, 2026. AWS names no replacement certification for ANS-C01."

这意味着纯网络 Specialty 方向的认证将从 AWS 体系里消失。对此有疑问的一个解读是：AWS 在重组 specialty 路线，部分内容可能被并入 SAP-C03 或未来的 Cloud Infrastructure Professional。如果你把 ANS-C01 列在备考清单里，12月31日前完成是最后窗口期——之后这张证书不再新发，但已持有者证书仍然有效。

> 来源：[AWS Exam Deadlines: SAP-C02, DVA-C02 and ANS-C01 – Daily Debian](https://dailydebian.com/blogs/it-certification-news/aws-sap-c02-dva-c02-ans-c01-deadlines-2026)

### 4. Microsoft MS-102 月底退役，接棒的是 AB-650

**一句话**：M365 管理员 Expert 认证 MS-102 在11月30日退役，建议直接切换到 AB-650 备考路线。

MS-102（Microsoft 365 Administrator Expert）是企业 M365 管理岗位最常见的认证，11月30日截止后不再发新证书。官方指定的接替考试是 AB-650：

根据 CertificationCamps 整理的退役列表：
> "MS-102 Microsoft 365 Administrator Expert retires November 30, 2026. Replacement: AB-650 Microsoft 365 and AI Services Administrator Associate."

AB-650 的名字里加入了"AI Services"，说明新版本要求考生掌握 Copilot for M365 和 AI 管理策略——这和 Microsoft 把整个认证体系往 AI 方向推的节奏一致。如果你公司正在推 M365 Copilot 部署，AB-650 的覆盖范围恰好对应这波需求。

另一个值得关注的动向：Dynamics 365 Supply Chain Management 的 MB-330 预计在12月迁移至 AB-330，AB-330 Beta 考试预计本月内开放，有兴趣先蹭便宜 Beta 价格的同学可以盯着 Microsoft Learn 公告。

> 来源：[Microsoft Certifications Retiring in 2026 – CertificationCamps](https://www.certificationcamps.com/microsoft-certifications-retiring/)

### 5. Google Cloud Professional Agentic Architect 正式上线，全球首张 AI Agent 架构认证

**一句话**：Google 在11月11日推出了 Professional Agentic Architect 认证——AI Agent 方向首张主流云厂商证书，hybrid 格式（笔试 + 实操 lab 双重认证）。

这张证书的特殊之处在于它不是传统单一笔试：

> "A hybrid certification with two parts: a proctored multiple-choice exam assessing foundational knowledge in agentic architecture, and Google Skills labs for hands-on work. Both parts are required."

根据 Google 官方博客（发布时间11月11日）：
> "Today we announced [the certification] for technical professionals, such as developers, cloud architects, and engineers who architect, build, and deploy agents on Google Cloud."

适合人群：已有 GCP Professional Cloud Architect 或 Developer 证书、正在做 AI Agent 项目的工程师。考前备考路径 Google 建议报名 Gemini Agent Ready 计划（包含每月免费 Google Skills 学习积分和 lab 访问权限）。日语版将于11月19日上线。

考试费用目前未公布，建议直接去 [cloud.google.com/learn/certification](https://cloud.google.com/learn/certification) 注册。

> 来源：[Google Cloud Blog – Professional Agentic Architect](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/professional-agentic-architect/) / [Google Developer Forums](https://discuss.google.dev/t/introducing-the-new-google-cloud-professional-agentic-architect-certification/412997)

## 二、免费 / 限免课程

### 1. DeepLearning.AI × Hugging Face：Building Code Agents with smolagents

**适合**：有 Python 基础、想动手搭 AI Agent 的开发者，不需要 AI 背景
**链接**：[deeplearning.ai/courses/building-code-agents-with-hugging-face-smolagents](https://www.deeplearning.ai/courses/building-code-agents-with-hugging-face-smolagents)

根据 DeepLearning.AI 课程页面：
> "Course access is free for a limited time during the DeepLearning.AI learning platform beta!"

课程长54分钟，包含7个视频 lesson + 4个代码示例 + 1个评分作业。核心内容：

- 代码 agent 和 tool-calling agent 的差异，以及什么场景选哪个
- 用 smolagents（Hugging Face 的轻量级 agentic 框架）构建代码 agent
- 如何安全地运行 LLM 生成的代码（沙箱 / 权限控制）
- 评估单 agent 和多 agent 系统，包括一个能在线搜索信息的 deep-research agent

smolagents 是目前社区里最轻量的 agent 框架之一，代码量少，适合理解原理。这门课几乎是入门 agentic 编程最高性价比的选择。

Completion certificate 需要 DeepLearning.AI PRO 会员；但 beta 期间所有课程内容和代码 lab 是免费的，不需要 PRO。
