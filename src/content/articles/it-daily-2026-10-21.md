## 一、认证动态

### 1. GitHub Copilot GH-300 考纲 8 月 7 日大改版：Agent Mode、MCP、Sub-Agents 全纳入

**一句话**：GitHub 于 8 月 7 日更新 GH-300 考纲，AI 编程 Agent 能力首次成为正式考点，备考内容需全面更新。

GH-300（GitHub Copilot）是 GitHub 官方 6 个认证之一，目前从 Pearson VUE 报名，通过分数 700/1000。最新官方 Study Guide 明确标注 **"Skills measured as of August 7, 2026"**，核心改动集中在 "Use GitHub Copilot features and capabilities" 域（25–30%），原文增加了以下新考点：

> "Use Agent Mode, Copilot Edits, and MCP for enhanced development and workflows; manage Agent Sessions and delegate tasks to Sub-Agents for optimized context usage"
>
> "Utilize Spaces, Spark, Pull Request summaries, and customizable review standards via instructions files"

此外 "Use GitHub Copilot in the IDE" 也做了 Minor 级别更新，涵盖 CLI 触发、Agent Mode 和 Content Exclusions。六大域权重：
- Use GitHub Copilot responsibly：15–20%
- Use GitHub Copilot features：25–30%（最大权重）
- Understand data and architecture：10–15%
- Apply prompt engineering：10–15%
- Improve developer productivity：10–15%
- Configure privacy and safeguards：10–15%

**对考生的影响**：如果你用的是 8 月之前的备考材料，MCP 集成、Agent Sessions、Sub-Agents 这三块没有任何覆盖——这些在新考纲里合计属于最大权重域，建议直接下官方 Study Guide 重新对照。Microsoft Learn 上有两条免费学习路径（GitHub Copilot Fundamentals Part 1 & 2）是官方推荐备考资源，零成本刷完可打底。

> 来源：[Study guide for Exam GH-300: GitHub Copilot — Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-300)

### 2. Google Cloud Professional ML Engineer 改版：全面替换为 Gemini Enterprise Agent Platform

**一句话**：Google Cloud 官方已更新 Professional ML Engineer 考纲，原 Vertex AI 产品线考点换成 Gemini Enterprise Agent Platform，$200 报名。

官方认证页面明确说明本次更新原因：

> "The exam was updated to reflect recent branding changes and the transition from Vertex AI to Gemini Enterprise Agent Platform, as well as updates to Google Cloud's data and analytics stack."

考试基本参数（官方页面）：

| 项目 | 数据 |
|---|---|
| 费用 | $200 USD（不含当地税） |
| 时长 | 2 小时 |
| 题目 | 50–60 题（多选 + 单选） |
| 语言 | 英语、日语 |
| 推荐经验 | 3 年以上业界经验，其中 1 年 Google Cloud 设计及管理经验 |

新考纲特别点名的产品域：Gemini platform、Gemini for business、Gemini for customer experience、gen AI models、foundation-model-based solutions。原来备考 Vertex AI AutoML 和 Vertex AI Workbench 的内容仍有保留，但优先级已让位于 Gemini 生态。

官方同时强调"the exam prioritizes Google Cloud native solutions"——第三方 ML 框架对比类题目不是重点，Gemini API 和 Google Cloud AI 产品集成才是主考方向。

> 来源：[Google Cloud Certification — Professional Machine Learning Engineer](https://cloud.google.com/learn/certification/machine-learning-engineer)

### 3. CNCF CARE 新规：通过 CKS = CKA 自动续期（6 月 18 日已生效）

**一句话**：自 2026 年 6 月 18 日起，考过或续期 CKS，你的 CKA 到期日会自动更新为与 CKS 一致——即使 CKA 已过期也能重新激活。

CNCF 官方博客（2026/06/17）原文：

> "Starting June 18, passing the CKS exam or recertifying CKS also reinstates or extends your CKA certification. Your CKA expiration date will be updated to match your new CKS expiration date. This applies whether your CKA is still active or has already expired."

背景：CKS（Certified Kubernetes Security Specialist）本身建立在 CKA 技能之上，CNCF 认为通过 CKS 即证明考生仍掌握 CKA 所测核心运维能力，因此纳入 CARE（Certification Advancement & Recertification Experience）体系。

**实操意义**：CKA 考试费 $445，三年要续一次。如果你已经在准备 CKS，考过之后就不需要单独重考 CKA，直接省 $445。对已经是 Kubestronaut 的学员，续期 CKS 同样维持 CKA 有效，减少需要追踪的证书到期日。

> 来源：[Expanding CARE: Passing CKS can now extend your CKA certification — CNCF Blog](https://www.cncf.io/blog/2026/06/17/expanding-care-passing-cks-can-now-extend-your-cka-certification/)

### 4. Oracle 2026 认证重构：OCI 系列免费 + 10 月上线 Exadata Professional

**一句话**：Oracle 今年把 OCI Foundations、AI Foundations、Data Platform Foundations 和 OCI Architect Associate 全部改为免费考试，另有 Exadata Database Service Professional 于 10 月上线。

根据第三方备考资讯整理（以下数据请在 [oracle.com/education](https://www.oracle.com/education/training/) 核实）：

- **OCI Foundations Associate（1Z0-1085-26）**：免费考，覆盖 Oracle Cloud 基础架构入门，适合零基础
- **AI Foundations Associate**：免费考，面向 AI/ML 业务用例
- **Data Platform Foundations Associate**：免费考
- **OCI Architect Associate**：课程 + 认证考试均已免费（2026 年政策调整）
- **Exadata Database Service Professional**：2026 年 10 月新上线，面向数据库专业岗位

以上 "-25" 后缀旧版考试已于 2026 年 6 月 22 日退役，目前均为 "-26" 后缀最新版。

如果你的目标是以最低成本拿第一张云认证，OCI Foundations（免费）是目前 AWS/Azure/GCP/Oracle 四家里门槛最低、成本最少的入口。

> 来源：[Oracle Certification 2026 Changes — PracticeTestSoftware（第三方，数据需在 oracle.com 核实）](https://www.practicetestsoftware.com/blog/oracle-certification-2026-program-changes/)

## 二、免费 / 限免课程

### 1. DeepLearning.AI Context Engineering（Chroma）—— 视频全免费，18 小时 56 分

**适合**：有 Python 基础、正在做 AI Agent 开发或想系统学 Context Management 的工程师
**链接**：[deeplearning.ai/short-courses/context-engineering](https://www.deeplearning.ai/short-courses/context-engineering/)

Jeff Huber（Chroma CEO）主讲，Drew Breunig（O'Reilly《Context Engineering Handbook》编辑）担任客座讲师。官方页面介绍：

> "Build more reliable and efficient AI agents through more relevant and focused context."

课程规模：37 个视频课、8 个代码示例、6 个评分作业。四大模块：

1. **Context Engineering 导论**：什么构成 Agent 的 Context，Context 如何退化，长对话中的失效模式
2. **Agentic Search**：Lexical、Semantic、Hybrid 检索策略，分块和 Metadata 优化
3. **Context Management**：Pruning（剪枝）、Compaction（压缩）、Offloading（卸载），Scratchpad 设计
4. **Agentic Memory**：跨 Session 存储 / 检索 / 更新记忆，评估记忆是否真的减少了重复指令

**费用说明**：视频全部免费；评分作业 + 结课证书需要 DeepLearning.AI PRO 订阅（$25/月 按年结算，$30/月 按月结算）。如果只是学知识不需要证书，$0 就能看完全部视频。
