## 一、认证动态

### 1. Snowflake 大洗牌：11月已退两张，12月1日再清两张，新增 MLOps 认证

**一句话**：Snowflake 两周内完成了近年最大规模认证调整，4 张证书退出、1 张新增、Core 基础考试换版本。

根据第三方认证追踪站 FalconCert（2026年11月4日数据），Snowflake 11月1日起正式调整认证目录：

**已退出（11月1日生效）**：
- **SnowPro Associate: Platform (SOL-C01)**：关联课程和学习路径已从 Snowflake 官网下架
- **SnowPro Advanced: Data Scientist**：被取消，不再独立存在

**考试版本更新**：
- **SnowPro Core** 从 COF-C02 升级为 **COF-C03**，这是 Snowflake 认证体系的基础证书，所有高级路径的前提；已经在备考 COF-C02 的考生注意核对当前报名的是哪一版本

**新增**：
- **SnowPro Advanced: MLOps Engineer (MLA-C01)**：面向在 Snowflake 平台上构建和部署机器学习管道的工程师角色

**即将退出（12月1日截止）**：
- **SnowPro Advanced: Security Engineer (SEA-C01)**
- **SnowPro Advanced: Data Analyst (DAA-C01)**

这两张证书没有官方宣布的接替考试。有这两张证书在计划中的考生，12月1日前完成考试是唯一窗口，只剩 17 天。

> 来源：[Snowflake Certifications in 2026 – FalconCert](https://falconcert.com/guides/snowflake-certification-path)（注：数据来自第三方，建议在 [learn.snowflake.com/en/certifications](https://learn.snowflake.com/en/certifications/) 核对官方列表后再预约）

**一句话**：两个重叠的截止日明天、后天到期，今天是两个福利同时可用的最后一天。

这是昨天日报的跟进提醒（详细内容见 11月13日日报）：

今天是 SAP-C02 还在活动窗口内的最后一天——今天预约、明天或后天考完，可以同时享受折扣和补考资格。错过今天，SAP-C02 只剩后天一天，但明天折扣活动就关闭了。

### 3. DVA-C02 本月底截止：DVA-C03 新考纲删掉了哪些内容？

**一句话**：DVA-C02 11月30日停考，DVA-C03 12月1日上线，但新版删除了 SageMaker、RAG 和 prompt engineering，考方向变了。

AWS 官方博客（September 2026 update）原文：*"The last day to take the current version of the exam (DVA-C02) will be November 30, 2026, with GA delivery beginning December 1, 2026."* 新版标准价格 $150 USD，注册通道 10月27日已开放。

**DVA-C03 考纲移除了什么？**

DVA-C03 四个领域权重不变（开发 30% / 安全 26% / 测试部署 22% / 故障排查 22%），但从考纲正式移除了：
- Amazon SageMaker AI 相关题目
- Retrieval-Augmented Generation (RAG) 架构设计
- Prompt engineering 技术

这部分内容整体迁移到 AWS AI 专项认证路径（AIF-C01 AI Practitioner 等），不再出现在通用 Developer Associate 里。同时备考 Developer + AI 两条线的学员：DVA-C03 的备考精力可以更集中在 Lambda、DynamoDB、API Gateway、CI/CD 核心内容，不必在 SageMaker 和 RAG 上花时间。

> 来源：[AWS Training & Certification Blog – September 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 4. Databricks Genie 接入 Claude、ChatGPT、Copilot、Grok

**一句话**：Databricks 11月11日推出 Genie 原生插件，认证学员现在可以直接在 Claude 或 Copilot 里调用 Genie 查询 Delta Lake 数据。

根据 Unite.AI 对 Databricks 11月11日公告的报道，Databricks 推出了 Genie AI Agent 插件，支持四个平台：
- **Claude（Anthropic）**
- **ChatGPT（OpenAI）**
- **Microsoft Copilot Cowork**
- **Grok Bot（xAI）**

Genie 是 Databricks 的自然语言数据查询 Agent，插件形式意味着不需要打开 Databricks 界面，直接在 Claude 对话里提问就能查询关联的数据仓库。

**对认证备考的影响**：备考 Databricks Certified Data Engineer Associate 或 Databricks Certified Machine Learning Professional 的学员有了新的实战练习方式——用 Claude 对 Databricks 实例提问，逐步建立对 Delta Lake 和 Unity Catalog 的直觉。对建立实际工作流理解有帮助，同时也是可以写进简历项目经验的真实工具使用案例。

> 来源：[Databricks Launches Native Genie Plugins for Four AI Agents – Unite.AI](https://unite.ai/databricks-launches-native-genie-plugins-for-four-ai-agents/)（2026年11月11日）

## 二、免费 / 限免课程

### 1. Hugging Face AI Agents Course：4章全覆盖，完全免费含证书

**适合**：有 Python 基础、想系统学 AI Agent 开发的中级学员（比昨日推荐的 smolagents 单节课更完整）
**链接**：[huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course)

这是一套完整的 AI Agent 课程体系，官方说明：*"This course is free, and the certification process is completely free."* 课程内容：

| 章节 | 核心内容 |
|------|---------|
| Chapter 1 | Agent 基础：Tools、Thoughts、Actions、Observations，LLM 和消息格式 |
| Chapter 2 | 三大框架横向对比：smolagents / LangGraph / LlamaIndex |
| Chapter 3 | 真实项目实战：用 Agent 解决具体任务 |
| Chapter 4 | 期末作业：构建 Agent 提交到学员排行榜 |
| Bonus 1 | 给函数调用微调 LLM |
| Bonus 2 | Agent 可观测性和评估 |
| Bonus 3 | 游戏中的 Agent（用 Pokémon 实战） |

**证书说明**：完成 Chapter 1 可获得免费基础认证；完成 Chapter 1 + 一个 Use Case + 期末作业可获得完整结课证书。无截止日期。

如果你昨天已经刷完了 smolagents 54分钟课，今天可以直接从 Chapter 2 的 LangGraph 和 LlamaIndex 对比模块开始，把三大 Agent 框架的差异理清楚，对准备 AI 工程师面试很有帮助。

> 来源：[Hugging Face AI Agents Course](https://huggingface.co/learn/agents-course)（官方说明：This course is free, and the certification process is completely free.）

### 2. Google Skills AI 学习路径：3,000+ AI 课程，部分免费

**适合**：准备 Google Cloud Professional Data Engineer、ML Engineer 认证的学员，或需要 GCP AI 实战经历的初中级工程师
**链接**：[cloudskillsboost.google](https://www.cloudskillsboost.google)

Google 将 Cloud Skills Boost 整合为 Google Skills 统一平台，提供超过 3,000 门 AI 课程和动手实验（hands-on labs）。平台内容分为四大 AI 学习路径：
1. **生成式 AI 应用构建**（GenAI App Development）
2. **ML 模型管理与安全**（ML Model Management & Security）
3. **AI 内容生成**（Content Generation）
4. **AI 数据分析**（AI-Powered Data Analysis）

每条路径包含视频课 + 实验环境。入门级内容（Introduction to Generative AI、Google Cloud Essentials）完全免费，动手实验按小时计费。

对于同时备考 AWS 和 GCP 双云的学员：先用 AWS Skill Builder 打通 SAA-C03，再用 Google Skills 补 GCP 的 Data Engineering 路径，两边都拿到 Associate 级别证书，简历的云覆盖度提升明显。

> 来源：[Google Rolls Out Skills Platform for AI, Tech Training – MIT Sloan Management Executive Education](https://www.mitsloanme.com/article/google-rolls-out-skills-platform-for-ai-tech-training/)（报道：Google announced a new centralized learning platform with more than 3,000 AI courses and hands-on labs）
