## 一、认证动态

### 1. Google Cloud Professional Agentic Architect 今日正式发布——AI Agent 架构师有了行业认证

**一句话**：Google Cloud 在 2026 年 11 月 12 日推出全球首个 AI Agent 架构专项认证，考试分两部分：在线监考 MCQ + Google Skills 实操 Lab，5 大考试域覆盖从 low-code 构建到生产安全治理的全链路。

Google Cloud 今天发布了 Professional Agentic Architect（PAA）认证，定位是证明你能在 Google Cloud 上设计、构建、评估并安全部署生产级 AI Agent。这不是传统的纯笔试——考试分两个必须都过的部分：

- **Part 1**：监考 MCQ，考系统设计决策、架构标准、成本优化和安全治理
- **Part 2**：Google Skills 实操 Lab，在真实 Cloud 环境里构建、测试、调试 Agent 工作流

五个考试域：(1) 用 low-code 工具构建 Agent；(2) 用 coding Agent 做应用开发；(3) 在 Gemini 平台 + 开源框架上开发自定义 Agent；(4) 评估和部署 Agentic 工作流；(5) Agent 安全与治理。

考试注册入口：[cloud.google.com/learn/certification/agentic-architect](https://cloud.google.com/learn/certification/agentic-architect)。备考路径建议先拿 GEAR 每月 35 积分（见下方免费课程第 1 条）把实操 Lab 练熟再报考。

> 来源：[Google Cloud Blog — Google Cloud Agentic Architect Certification（2026-11-12）](https://cloud.google.com/blog/topics/training-certifications/google-cloud-agentic-architect-certification-dont-just-prompt-ai-design-it)

### 2. AWS DVA-C02 本月 30 日退役——DVA-C03 注册已开，新增 Amazon Q Developer 和 Bedrock 内容

**一句话**：AWS Developer Associate 旧版考试（DVA-C02）11 月 30 日停考，新版 DVA-C03 在此前已开放注册，重点更新了 AI 集成开发场景。

AWS 官方 2026 年 10 月 27 日博文明确写道：**DVA-C02 最后考试日期是 2026 年 11 月 30 日**，从 12 月 1 日起全面切换到 DVA-C03。

新版 DVA-C03 的核心变化：在原有 Lambda / API Gateway / DynamoDB 场景基础上，加入了 **Amazon Q Developer 辅助开发**和 **Amazon Bedrock 基础集成**两个新知识点，反映 AWS 开发工作流 AI 化的现实。四大考试域权重（来自第三方整理，建议用官方 Exam Guide 核对）：Development with AWS Services (30%) / Security (26%) / Testing and Deployment (22%) / Troubleshooting and Optimization (22%)。

**现在怎么做**：
- 还没考 DVA-C02 的：本月底前有 Pearson VUE 在线监考位，可以冲一次旧版；但如果准备时间不足两周，直接备 DVA-C03 更划算，不必背注定退场的内容。
- 已经在备考 DVA-C02 的：差得不多就本月内考掉；差很多请切 DVA-C03，官网已有对比新旧大纲的 Exam Guide。

注册链接：[aws.amazon.com/certification/certified-developer-associate](https://aws.amazon.com/certification/certified-developer-associate/)

> 来源：[AWS Training and Certification Blog — Register now: Updated Developer Associate exam（2026-10-27）](https://aws.amazon.com/blogs/training-and-certification/register-now-updated-developer-associate-and-solutions-architect-professional-exams/)

### 3. Snowflake 两张 Advanced 证书下月 12 月 1 日停考——SEA-C01 和 DAA-C01 进入倒计时 19 天

**一句话**：Snowflake 官网确认 SnowPro Advanced: Security Engineer（SEA-C01）和 SnowPro Advanced: Data Analyst（DAA-C01）均于 2026 年 12 月 1 日起停考，今天起最多还剩 19 天考试窗口。

Snowflake 认证页面直接列出：

> *"SnowPro® Advanced: Security Engineer (SEA-C01) — Retiring December 1, 2026"*  
> *"SnowPro® Advanced: Data Analyst (DAA-C01) — Retiring December 1, 2026"*  
> 来源：[learn.snowflake.com/en/certifications](https://learn.snowflake.com/en/certifications/)

这两张证书退场后，Snowflake 目前在售的 Advanced 路径剩下：Architecture、Data Engineering、Data Lake 和 Data Science（COF-C03 核心也已于 2026 年 2 月升版）。新增的 AI Governance & Security Specialty（ADS-B01）可以作为 SEA 方向的延伸。

如果你正在准备这两张证书，这个月底之前务必在 Webassessor 预约考位。已持有的证书不受退场影响，不需要立刻重考。

> 来源：[Snowflake Certification 官网](https://learn.snowflake.com/en/certifications/)

### 4. Microsoft MS-102 管理员专家 11 月 30 日退役——AB-650 接档，Beta 阶段可折价尝鲜

**一句话**：微软 M365 Administrator Expert（MS-102）本月 30 日停考，接替的 AB-650（AI Services Administrator）已进 Beta 阶段，Beta 考试费通常为正价的 80% 折扣。

MS-102 是微软三年来最稳定的高级认证路径之一，11 月 30 日之后**不再可以报名或续期**。接替它的是 AB-650 AI Services Administrator，该证书目前处于 Beta 状态，尚无正式 GA 日期。

Beta 考试参加方式：前往 [learn.microsoft.com/certifications](https://learn.microsoft.com/certifications) 搜索 "AB-650"，Beta 注册通常需要填写候补名单。Beta 阶段不会立即出成绩，要等 Beta 结束 + 评分标准确定后才公布（通常几周到 2 个月）。好处是费用是正价的 80%，且这段时间反馈 bug 对认证社区有贡献。

注意：MS-102 持有者的 M365 Administrator Expert 徽章在 11 月 30 日后不可续期。如果需要保留徽章，AB-650 通过后会颁发新的 Expert 认证。

> 来源：[vladtalkstech.com — Microsoft Certification Retirements 2026](https://vladtalkstech.com/microsoft-learning-and-credential-news/microsoft-certification-retirements-2026/) （第三方整理，请在 learn.microsoft.com 核对最终日期）

## 二、免费 / 限免课程

### 1. Google GEAR 计划：每月 35 积分解锁 Google Skills Labs——Professional Agentic Architect 官方备考路径

**适合**：已有 Google Cloud 基础（Associate Cloud Engineer 或同等水平），计划备考 Professional Agentic Architect 认证的开发者和架构师  
**链接**：[developers.google.com/program/GEAR](https://developers.google.com/program/GEAR) 和 [cloud.google.com/resources/offers/skill-up-in-ai](https://cloud.google.com/resources/offers/skill-up-in-ai)

GEAR（Gemini Agent Ready）是 Google Cloud 于 2026 年 2 月开放的免费学习计划，注册后每月发放 **35 learning credits**，可在 Google Skills 平台兑换 AI 相关课程和实操 Lab（Codelabs 不消耗积分，积分用于 Qwiklabs 实操环境）。

覆盖内容：Agent 生态系统 / 多智能体系统架构 / Agent 安全与治理 / Agent Development Kit (ADK) / 生产部署。这 5 个方向与今天发布的 Professional Agentic Architect 考试域完全对齐——GEAR Labs 本质上就是这个认证的官方练手资源。

注册时用和 Google Cloud 账号相同的邮箱，积分才会正确绑定。Codelabs 步骤式教程无需积分，可以先从 Codelabs 入手熟悉 Vertex AI Agent Builder 再消耗积分做完整 Lab。

### 2. Harvard CS50: Introduction to Cybersecurity——哈佛免费颁发证书，自学约 5 周

**适合**：IT 新人 / 转行者 / 希望补充安全基础的开发者，完全没有编程基础也能上手  
**链接**：[cs50.harvard.edu/cybersecurity](https://cs50.harvard.edu/cybersecurity)（也可从 edX 搜索入口访问）

Harvard CS50 的 Cybersecurity 课程是 CS50 系列里最受推荐的入门路径之一。完成所有作业和项目后，在 Gradebook 页面申请 **CS50 Certificate**——这是由哈佛 CS50 团队直接颁发的免费证书，不是 edX 的付费验证证书。edX 验证证书是另一个付费选项，两者独立。

课程时长约 5 周，自学节奏，内容覆盖：密码学基础 / Web 安全 / 账户与数据安全 / 现实攻击案例。全程英文，适合用来夯实 AWS Security Specialty 或 Snowflake SEA-C01 的安全基础。

### 3. Microsoft Learn：AI-901 / AI-103 准备路径——全部免费，无需 Azure 订阅

**适合**：准备 Azure AI Fundamentals（AI-901）或 Azure AI Engineer Associate（AI-103）的学员  
**链接**：[learn.microsoft.com/training/courses/embark-ai-journey-free-ai-tools-microsoft-education-3hr](https://learn.microsoft.com/en-us/training/courses/embark-ai-journey-free-ai-tools-microsoft-education-3hr)

Microsoft Learn 的所有学习路径（Learning Paths）均免费，无需订阅。适合现在开始备考的两条路：

- **AI-901 Fundamentals 路径**："AI concepts for developers and technology professionals"，约 3 小时 51 分钟，7 个模块，Beginner 级，涵盖机器学习、生成式 AI、Azure AI 服务概览
- **Embark on your AI journey with free AI tools from Microsoft**：3 小时，包含 Copilot Studio、Azure AI Studio 实操演示，不需要真实订阅（部分 Lab 需要 Azure 免费账户额度）

注意：Learn 平台的 Azure 实操沙箱已在 2026 年下架，部分 Lab 现在要求有自己的 Azure 账户。AI-901 类基础概念课不受影响，AI-103 实操部分建议用 Azure 免费账户额度（$200 新用户额度）跑。

### 4. AWS Skill Builder：免费 Builder Labs 学习计划——10 个基础 Lab，含 IAM 和 KMS

**适合**：AWS 完全新手 / 准备 Cloud Practitioner 的学员  
**链接**：[builder.aws.com](https://builder.aws.com)

AWS Skill Builder 有 900+ 免费数字课程（无证书），以及一套免费的 Builder Labs 学习计划，包含 10 个动手 Lab，覆盖 IAM（Identity and Access Management）和 KMS（Key Management Service）等基础服务。不需要 Skill Builder 付费订阅，注册 AWS 账号后直接从 builder.aws.com 进入即可。

如果正在备 DVA-C03，这里的免费课程可以先把 Lambda / API Gateway / DynamoDB 基础过一遍。付费 Skill Builder 订阅（每月 $29）才解锁 Official Practice Exams（模考），但自由备考期间用免费课程打底完全够用。
