## 一、认证动态

### 1. AWS SAP-C03 本周一（11月17日）正式开考，SAP-C02 本周日截止

**一句话**：备考 AWS 解决方案架构师专业级的，这个周末是最后一次走旧版 SAP-C02 的机会——周一起切换到 SAP-C03。

AWS 官方 September 2026 更新明确写道：**SAP-C02 的最后考试日是 2026年11月16日（本周日）**，从 **11月17日（本周一）** 起全球考场切换到新版 SAP-C03。考试注册通道已于10月27日开放。

如果你已报名 SAP-C02 但还没考，现在距截止还有 5 天——今天查 Pearson VUE 在线监考位或附近考场，把这个周末用上。如果还没开始备考，可以直接切 SAP-C03，新大纲把混合云多账号架构和 AI 工作负载的场景覆盖得更完整，不必勉强去刷即将退场的旧版本。

SAP-C03 官方 Exam Guide 已经发布，可在 AWS Certification 页面下载，价格和监考方式与旧版保持一致。

> 来源：[AWS Training and Certification September 2026 Update](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 2. AWS DVA-C03 开发者助理新版 12月1日 GA，DVA-C02 本月底退役

**一句话**：Developer Associate 换版本的时间比 SAP 宽一个月，但 11月30日是 DVA-C02 的绝对截止。

**AWS Certified Developer – Associate（DVA-C03）将于 2026年12月1日正式开考，同日 DVA-C02 退役。** 注册通道同样已于10月27日开放。DVA-C03 的更新重点是把 serverless 事件驱动架构、Step Functions、CodePipeline 和 Amazon Q Developer 的实际工作流整合进考试范围，减少了早期偏重 SDK 语法细节的题型。

**现在怎么选：**

- 已按 DVA-C02 大纲备了一段时间 → 本月内冲完，经济且稳
- 还没开始 → 直接按 DVA-C03 大纲备，12月1日直接考新版，知识体系更贴近2026年实际开发场景

> 来源：[AWS Training and Certification September 2026 Update](https://aws.amazon.com/blogs/training-and-certification/september-2026-new-offerings/)

### 3. MS-102 本月30日退役，AB-650（M365 AI 服务管理员）已 GA 接棒

**一句话**：M365 管理员方向的，MS-102 只剩19天，本月内能考就考；新替代证 AB-650 已于10月30日 GA，备考路径全免费。

**Microsoft 365 Certified: Administrator Expert（MS-102）将于2026年11月30日退役。** 微软官方 Credential Retirement 页面列明，接替它的是 **Microsoft 365 Certified: AI Services Administrator Associate（AB-650）**，已于2026年10月30日正式开考（GA），定位是"能管 AI 工具、也能管传统 M365 合规"的复合型管理员角色。

AB-650 的考试范围相比 MS-102 加入了大量 Microsoft 365 Copilot 管理、Azure AI 服务企业部署、Entra ID 权限治理和 Microsoft Purview 合规配置的内容。

**关键细节（来自微软 Partner Center 官方公告）：**

- **MS-102 退役前完成认证的，积分有效期延续到2027年11月30日**，对需要维持 Solutions Partner Modern Work 资格的合作伙伴来说，这个月内完成 MS-102 还是有意义的
- AB-650 现已纳入 Solutions Partner 对应的 advanced skilling metric，作为 MS-102 的直接替代

> 来源：[Microsoft Partner Center October 2026 Announcements](https://learn.microsoft.com/en-us/partner-center/announcements/2026-october)  
> [Microsoft Credential Retirement Page](https://learn.microsoft.com/en-us/credentials/support/credential-retirement)

### 4. CNCF 在 KubeCon NA 2026（盐湖城）正式发布 CKNE 认证

**一句话**：Kubernetes 网络工程师终于有了专属认证，CNCF 本周在盐湖城 KubeCon 上场，5大技术域覆盖从 CNI 到 Gateway API。

KubeCon + CloudNativeCon North America 2026 本周正在犹他州盐湖城 Salt Palace Convention Center 举行（11月9-12日），CNCF 在会上正式宣布推出 **Certified Kubernetes Network Engineer（CKNE）**——这是继 CKA（Certified Kubernetes Administrator）、CKS（Certified Kubernetes Security Specialist）之后，专门针对 Kubernetes 网络方向的全新实操认证，由 CNCF 和 Linux Foundation Education 联合开发。

**考试格式：120分钟性能考试（Performance-based）**，需在真实 Kubernetes 集群中完成实操任务，不是选择题。考试覆盖五大技术域：

| 域 | 权重 | 核心考点 |
|---|---|---|
| Core Infrastructure & CNI | 15% | CNI 插件配置、IPAM、Pod CIDR 分配、iptables/ip 工具 |
| Service Networking & DNS | 25% | L4 Services、kube-proxy、CoreDNS 自定义、Gateway API（HTTPRoutes）|
| Advanced Traffic Management | 20% | LLM 流量优化、egress gateway、跨集群服务发现与负载均衡 |
| Network Security & Policy | 25% | Network Policies、节点/Pod 加密、TLS 证书管理、Gateway API |
| Observability | 15% | 网络健康指标、端到端追踪、流量审计日志 |

**考试价格：** Linux Foundation 官网目前仍标注"开发阶段，测试期名额已截止"，第三方来源报测试期价格 $99（已截止），正式版预计约 $445（未经官方确认，建议到 [training.linuxfoundation.org](https://training.linuxfoundation.org/kubernetes-network-engineer-program/) 直接核查）。KubeCon 注册者可享受云原生培训/认证 40% 折扣优惠。

另外，CNCF 透露 2027 年还将推出 Kubernetes AI Associate（KAIA）和 Certified Kubernetes Inference Engineer（CKIE）两个新认证。

> 来源：[CNCF CKNE Certification Launch](https://efficientlyconnected.com/cncf-ckne-kubernetes-network-certification)  
> [Linux Foundation CKNE Program](https://training.linuxfoundation.org/kubernetes-network-engineer-program/)

## 二、免费 / 限免课程

### 1. AWS Skill Builder：220+ 免费 AI 课 + 微证书无需订阅

**适合**：准备 AWS AI 认证路径（AIF-C01 → MLA-C02 → AIP-C01）的学员，以及想系统了解 Gen AI、Agentic AI 的 IT 从业者  
**链接**：[https://skillbuilder.aws](https://skillbuilder.aws)

AWS Skill Builder 目前有 **220+ 门免费 AI 课**，从基础的"Generative AI Essentials"到进阶的"Building Agentic Workflows with Amazon Bedrock"都在里面，注册 Amazon 账号即可免费学，不需要信用卡。

更值得关注的是：**AWS 已把 Microcredentials 改为对全部用户免费**，不再要求付费 Skill Builder 个人版订阅（之前要 $29/月）。Microcredential 是完成一组课程后颁发的数字徽章，可挂 LinkedIn，对技术类简历的搜索可见度有实质性帮助。

在读大学生可额外申请 AWS AI & ML Scholars，拿到1年 Skill Builder 完整访问权限（2026 Challenge 期满额，但课程资源仍开放）。

> 来源：[AWS Free AI Skills Training Courses](https://www.aboutamazon.com/news/aws/aws-free-ai-skills-training-courses)

## 三、JR Academy 学员行动建议

**1. 本周末考掉 SAP-C02（如果已注册）**  
11月16日（周日）是绝对截止日，今天还有5天。现在就去 Pearson VUE 查附近考场或在线监考时段，把名报上。考前重点刷 VPC peering/Transit Gateway、Organizations 多账号架构、混合云连接（Direct Connect + VPN）这三块高频题型。

**2. M365 管理员方向：本月30日前报考 MS-102，或直接切 AB-650**  
MS-102 还有19天退役。已备考过半的，这个月内冲完；还没开始的，直接备 AB-650——新版含 Copilot 管理和 AI 合规，是2026年后 M365 管理员岗位真正在招的技能组合。备考资料在 Microsoft Learn 全部免费。

**3. 云原生工程师：先拿 CKA，同步补 CKNE 考点**  
CKNE 正式 GA 时间待定，现在最实际的路径：先完成 CKA（实力基础，不是 CKNE 的硬性前提但实际必备），同时开始补 CNI 配置、CoreDNS 自定义、NetworkPolicy 和 Gateway API 这些 CKNE 核心域，等官方开放时间公布直接报名。KubeCon 注册者目前有 40% 认证折扣。

**4. Developer Associate 备考中的：11月30日前考掉 DVA-C02**  
如果已按 DVA-C02 大纲备了超过一半，本月内拿证比切换到 DVA-C03 新版更经济——新版12月1日才开考，你有充足时间按原计划完成。

**5. 本周刷一门 AWS 免费 AI 课**  
AWS Skill Builder 上的"Amazon Bedrock Getting Started"（2小时左右）或"Foundations of Prompt Engineering"（3小时）都可以在一两天内完成，拿到 Microcredential 徽章直接挂 LinkedIn，求职季简历的技术关键词覆盖度会有明显提升。
