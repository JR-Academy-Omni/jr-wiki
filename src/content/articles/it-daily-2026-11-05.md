## 一、认证动态

### 1. Azure AZ-401 beta：折扣码 AZ401Glendon 享 80% off，11月9日截止

**一句话**：Agentic DevOps Engineer Expert 新认证 beta 阶段最多省 80%，只剩 4 天窗口。

新的 Microsoft Certified: Agentic DevOps Engineer Expert 认证取代现有 DevOps Engineer Expert（原 AZ-400 路线），beta 考试 AZ-401 现已开放报名。前 300 位考生用折扣码 **AZ401Glendon** 结账时可享 **80% 折扣**，截止日期 **2026 年 11 月 9 日（周日）**。

> **sourceQuote**："80% off for the first 300 candidates. Enter the code AZ401Glendon at payment during registration... You must take the exam on or before November 9, 2026. The discount isn't available in Turkey, Pakistan, India, or China."
> — [Microsoft Tech Community 官方公告](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-agentic-devops-engineer-expert/4528356)

考试内容涵盖 AI 辅助的 DevOps 实现，核心是 Azure DevOps + GitHub Copilot 集成，以及 CI/CD 管道设计（35–40%）、安全合规计划（15–20%）和监控策略（15–20%）。考试语言目前仅英文。

**拿证要求**（二选一）：
- 通过 AZ-401 + **GH-300**（GitHub Copilot 认证）
- 通过 AZ-401 + **AZ-104**（Azure Administrator Associate）

原 AZ-400 DevOps Engineer Expert 认证将于 **2027 年 2 月 1 日退场**：

> **sourceQuote**："AZ-400 and the Microsoft Certified: DevOps Engineer Expert certification retire on February 1, 2027."
> — [Microsoft Tech Community 官方公告](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-agentic-devops-engineer-expert/4528356)

已持有 AZ-400 的学员建议今年内规划 AZ-401 过渡，不要等到明年 1 月才开始备考。beta 阶段成绩不会立即出来，微软在正式版上线后统一评分，最终结果约 10 天内到账。

报名：[learn.microsoft.com/credentials/certifications/exams/az-401/](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-401/)

> 来源：[Microsoft Skills Hub Blog](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-agentic-devops-engineer-expert/4528356)

**一句话**：Solutions Architect Professional 新版本下周一落地，只剩 11 天考旧版。

> **sourceQuote**："SAP-C02 retirement: November 16, 2026 is the last day to take the current exam. SAP-C03 launch: Registration opens October 27, 2026, and GA delivery begins November 17, 2026."

### 4. GCP PMLE 2026 年 6 月考纲大更新：Gemini Agent + RAG 权重提升

**一句话**：Professional ML Engineer 新考纲已把 Vertex AI Pipeline 中心替换为 Gemini Enterprise Agent Platform，旧复习材料要重新核对。

GCP 于 2026 年 6 月 1 日更新了 PMLE 考纲，核心变化是把原来以 Vertex AI Pipeline 为重心的考核内容，转向 **Gemini Enterprise Agent Platform**、**RAG 设计**（Retrieval-Augmented Generation）和 **Vertex AI Agent Builder**。如果你正在刷 2025 年及更早的复习材料，建议对照新考纲检查覆盖度，尤其是 Agent 构建和 RAG pipeline 设计部分。

此外，Google 已将所有 GCP 认证考试切换到 **Pearson VUE** 交付（原 Kryterion）。澳洲学员一般影响不大，中国大陆学员需要重新确认本地 Pearson VUE 考点可用情况。

考纲：[cloud.google.com/certification/guides/professional-machine-learning-engineer](https://cloud.google.com/certification/guides/professional-machine-learning-engineer)

> 来源：[Google Cloud Certification Changes 2026（TestPrepTraining 整理）](https://www.testpreptraining.ai/blog/google-cloud-certification-exam-updates/)
